# OneRec：以生成式推荐与偏好对齐统一召回和排序

Jiaxin Deng 等8位作者，KuaiShou Inc.。固定 arXiv:2502.18965v1（2025-02-26）。

[原文PDF](https://arxiv.org/pdf/2502.18965v1) · 译后源码（本地附件，不随 Git 分发）：`.local/papers/SRC-ONEREC/translation/translated-sources/onerec.tex`

## 摘要

近年来，基于生成式检索的推荐系统（GR）通过自回归方式直接生成候选视频，成为一种有潜力的范式。然而，大多数现代推荐系统采用召回后排序的策略，生成模型仅在召回阶段充当选择器。本文提出**OneRec**，用统一生成模型替代级联学习框架。据我们所知，这是首个在真实场景中显著超越当前复杂、精心设计的推荐系统的端到端生成模型。
具体而言，OneRec 包含：1）**编码器—解码器结构**，编码用户历史行为序列，并逐步解码用户可能感兴趣的视频。我们采用稀疏混合专家（MoE），扩展模型容量而不使计算 FLOPs 同比例增加。
2）**会话级生成方式**。相较于传统下一物品预测，我们提出会话级生成；与依赖人工规则组合生成结果的逐点生成相比，它更简洁、上下文更连贯。3）**迭代偏好对齐模块**，结合直接偏好优化（DPO）提高生成质量。不同于 NLP 中的 DPO，推荐系统通常对每次用户浏览请求只有一次展示机会，因而无法同时获得正负样本。为解决这一限制，我们设计奖励模型来模拟用户生成过程，并根据推荐系统在线学习的特点定制采样策略。
大量实验表明，有限数量的 DPO 样本能够对齐用户兴趣偏好，并显著提高生成质量。我们将 OneRec 部署在拥有数亿日活用户的短视频平台快手主场景，观看时长提升了 1.6%，取得显著改善。

关键词：生成式推荐，自回归生成，语义 Token 化，直接偏好优化

## 引言

为平衡效率与效果，大多数现代推荐系统采用级联排序策略［6,26,43,34］。如图1(b)，典型系统包含三个阶段：召回［6,19,54］、粗排［28,46］和精排［2,15,16,52,53,33,3］。每个阶段从收到的物品中选择前$k$个，传递给下一阶段，共同平衡系统响应时间与排序准确性。

图1：(a) 提出的端到端统一生成架构。(b) 典型级联排序系统，从下至上为召回、粗排和精排。

[原图，图内英文保留（原文 PDF）](https://arxiv.org/pdf/2502.18965v1)

现有方法在实践中高效，但通常独立处理每个排序器；各阶段的效果构成后续阶段的上限，限制整个系统的表现。尽管已有研究［13,11,18,34,20,44］通过排序器间交互改善总体推荐效果，它们仍保留传统级联范式。近年来，基于生成式检索的推荐系统（GR）［36,45,51］通过自回归序列生成直接输出候选物品标识，成为有潜力的新范式。以编码物品语义的量化语义 ID 索引物品［24］，使推荐器能够利用丰富的物品语义信息。GR 的生成特性使其适合通过 beam search 解码直接选择候选物品，并产生更多样的结果。但目前生成模型仅充当召回阶段的选择器，其推荐准确性尚不能匹敌精心设计的多级排序器。

为解决这些问题，我们提出统一的端到端单阶段生成式推荐框架**OneRec**。首先，采用编码器—解码器结构。受大语言模型扩展规律启发，我们发现扩大推荐模型容量也能持续改善效果，因此使用 MoE 结构［55,9,7］扩大参数量，增强用户兴趣刻画能力。其次，不同于逐点预测下一物品，我们提出会话级列表生成，考虑会话内物品的相对内容与顺序。逐点生成需要人工策略保证结果的连贯性与多样性；会话级学习则通过偏好数据让模型自主学习理想会话结构。最后，通过直接偏好优化（DPO）［35］进一步改善生成质量。构造偏好对时，受困难负采样［37］启发，我们从 beam search 结果中构造自身生成的困难拒绝样本，而非随机采样。迭代偏好对齐（IPA）使用预训练奖励模型（RM）为采样响应排序，选出最优接受与最差拒绝样本。大规模工业数据实验展示了方法的优势，消融实验进一步检验各模块。主要贡献如下：

-  为克服级联排序限制，我们提出单阶段生成式推荐框架 OneRec。
据我们所知，这是较早使用统一生成模型处理物品推荐并显著超越传统多阶段排序流水线的工业方案之一。

-  通过会话级生成，强调模型容量与目标物品上下文信息的必要性，以改善预测准确性和生成物品多样性。

-  提出基于个性化奖励模型的自身困难负例选择策略，通过 DPO 增强对更广泛用户偏好的泛化，并用离线与在线 A/B 实验验证效果和效率。

图2：**OneRec 整体框架，包含两阶段：(i) 使用会话级数据训练；(ii) 用自身困难负例执行迭代直接偏好优化的 IPA 阶段。**

## 相关工作

### 生成式推荐

随着生成模型快速发展，生成式推荐受到越来越多关注。传统嵌入检索主要依赖双塔模型计算候选评分，并使用高效的 MIPS 或 ANN 搜索系统［17,31,38,14,21］检索前$k$个相关物品。生成式检索（GR）［41］把数据库中的相关文档检索改写为序列生成任务，依次生成文档 Token；这些 Token 可以是文档标题、文档 ID 或预训练语义 ID［42］。GENRE［8］首先以 Transformer 进行实体检索，根据上下文自回归生成实体名称。DSI［42］首先提出为文档分配结构化语义 ID，并训练编码器—解码器进行生成式文档检索。沿着这一范式，TIGER［36］把生成式物品检索引入推荐系统。

除生成框架外，物品索引方式也备受关注。语义索引研究［36,42,12］根据内容信息为物品建立索引。具体而言，TIGER［36］与 LC-Rec［51］对标题、描述得到的文本嵌入应用残差量化（RQ-VAE）进行 Token 化。Recforest［12］对物品文本嵌入执行层次 K-means，以簇索引作为 Token。EAGER［45］等近期研究进一步探索在 Token 化过程中融合语义与协同信息。

### 语言模型偏好对齐

大语言模型（LLM）的后训练阶段［10］常使用基于人类反馈的强化学习（RLHF）［39,32］：以表达人类反馈的奖励模型指导强化学习，使 LLM 与人类价值观对齐。但 RLHF 存在不稳定和低效率问题。直接偏好优化（DPO）［35］推导最优策略的闭式形式，直接利用偏好数据优化模型。后续变体进一步改善原始 DPO。例如，IPO［1］以一般目标绕过 DPO 的两项近似；cDPO［35］引入超参数$\epsilon$缓解标签噪声；rDPO［5］设计原始二元交叉熵的无偏估计；CPO［47］、simDPO［5］等也从不同方面增强或扩展
DPO。然而，传统 NLP 通常由人类显式标注偏好，推荐系统的用户—物品交互稀疏性则给偏好学习带来独特挑战，因此 DPO 在推荐中的适配仍少有探索。S-DPO 侧重于给基于语言模型的推荐器引入多个负例；我们则训练奖励模型，根据其评分为不同用户选择个性化偏好数据。

## 方法

本节提出 OneRec，通过单阶段检索方式生成目标物品的端到端框架。第3.1节先介绍工业单阶段生成式推荐的特征工程；第3.2节定义会话级生成任务并介绍模型架构；第3.3节解释个性化奖励模型如何支持自身困难负例采样，以及如何通过 DPO 迭代提升模型。整体框架见图2。

### 预备知识

我们先从特征工程介绍单阶段生成式推荐链路。用户侧以正反馈历史行为序列$\mathcal{H}_u=\{\bm{v}^{h}_1, \bm{v}^{h}_2,\ldots, \bm{v}^{h}_n\}$为输入，其中$\bm{v}$表示用户有效观看或发生点赞、关注、分享交互的视频，$n$为行为序列长度。OneRec 输出视频列表，组成会话$\mathcal{S} = \{\bm{v}_1, \bm{v}_2, ..., \bm{v}_m\}$，$m$是会话内视频数（会话的详细定义见第3.2节）。

对每个视频$\bm{v}_i$，使用与真实用户—物品行为分布对齐的多模态嵌入$\textbf{\textit{e}}_i \in \mathbb{R}^{d}$表示［27］。已有生成式推荐框架［25,36］使用 RQ-VAE［49］把预训练多模态嵌入编码为语义 Token，但码分布不均衡，即沙漏现象［23］，会使其效果欠佳。我们用残差 K-Means 量化算法［27］进行多层均衡量化，转换$\textbf{\textit{e}}_i$。第一层（$l = 1$）的初始残差为$\bm{r}_i^{1} =\bm{e}_i$；每层$l$都有包含$K$个码字的码本$\mathcal{C}_{l}=\{\bm{c}_1^{l},...,\bm{c}_K^{l}\} $。最近质心嵌入的索引为$\bm{s}_i^l = \arg\min_{k}\|\textbf{\textit{r}}_i^{l} - \bm{c}_k^{l}\|_2^2$，下一层$l + 1$的残差定义为$\bm{r}_i^{l + 1} =\bm{r}_i^{l} -  \bm{c}_{\bm{s}_i^l}^{l}  $。据此通过层次索引生成相应码本 Token：

$$
\begin{aligned}
&\bm{s}_i^1 = \arg\min_{k}\|\bm{r}_i^{1} - \bm{c}_k^{1}\|_2^2, \quad \bm{r}_i^{2} =\bm{r}_i^{1} -  \bm{c}_{\bm{s}_i^1}^{1}  \\
&\bm{s}_i^2 = \arg\min_{k}\|\bm{r}_i^{2} - \bm{c}_k^{2}\|_2^2, \quad \bm{r}_i^{3} =\bm{r}_i^{2} -  \bm{c}_{\bm{s}_i^2}^{2}  \\
&\qquad\qquad\vdots \\
&\bm{s}_i^L = \arg\min_{k}\|\bm{r}_i^{L} - \bm{c}_k^{L}\|_2^2 \\
\end{aligned}
$$

其中$L$为语义 ID 的总层数。

为构造均衡码本$\mathcal{C}_l = \{\bm{c}_1^l, \ldots, \bm{c}_K^l\}$，我们按**算法1**使用 Balanced K-means 划分物品集。给定全部视频集$\mathcal{V}$，算法将其分为$K$个簇，每簇恰好包含$w = |\mathcal{V}|/K$个视频。迭代时，按欧氏距离依次为每个质心分配最近的$w$个尚未分配视频，再用已分配向量的均值更新质心。簇分配收敛时停止。

算法1：均衡 K-means 聚类

输入物品集 $\mathcal V$ 与簇数 $K$，计算 $w=|\mathcal V|/K$，随机初始化质心。

1. 重复到分配收敛：令未分配集合 $\mathcal U=\mathcal V$。
2. 对每个簇 $k=1,\ldots,K$，按到质心 $\bm c_k^l$ 的距离升序排列 $\mathcal U$。
3. 分配 $\mathcal V_k\gets\mathcal U[0:w-1]$；更新 $\bm c_k^l\gets w^{-1}\sum_{\bm r^l\in\mathcal V_k}\bm r^l$。
4. 从 $\mathcal U$ 移除 $\mathcal V_k$，继续下一簇；输出优化码本。

### 会话级列表生成

传统逐点推荐只预测下一个视频，会话级生成则根据用户历史交互序列生成高价值会话列表，捕捉推荐列表中视频的依赖关系。会话指一次用户请求返回的一批短视频，通常包含 5 至 10 个视频，兼顾用户兴趣、连贯性和多样性。我们用以下标准识别高质量会话：

-  用户在该会话实际观看的短视频数大于或等于5；

-  用户在该会话的总观看时长超过某阈值；

-  用户有点赞、收藏、分享等交互行为；

这种方式使会话级模型从真实参与模式中学习，捕获更准确的会话列表上下文。因此，会话级模型$\mathcal{M}$的目标可写为：

$$
\mathcal{S} :=\mathcal{M}(\mathcal{H}_u)
\tag{1}
$$

其中$\mathcal{H}_u$由语义 ID 表示：$\mathcal{H}_u = \{ (\bm{s}_1^1, \bm{s}_1^2, \cdots,   \bm{s}_1^L),  (\bm{s}_2^1, \bm{s}_2^2, \cdots, \bm{s}_2^L), \cdots, (\bm{s}_n^1, \bm{s}_n^2, \cdots, \bm{s}_n^L) \}$，目标会话为$\mathcal{S} = \{ (\bm{s}_1^1, \bm{s}_1^2, \cdots, \bm{s}_1^L),  (\bm{s}_2^1, \bm{s}_2^2, \cdots, \bm{s}_2^L), \cdots, (\bm{s}_m^1, \bm{s}_m^2, \cdots, \bm{s}_m^L) \}$。

如图2(a)，模型采用与 T5［48］一致的 Transformer 框架，包含建模用户历史交互的编码器与生成会话列表的解码器。编码器使用堆叠的多头自注意力和前馈层处理$\mathcal{H}_u$，编码后的历史交互特征记为$\textbf{\textit{H}}=Encoder(\mathcal{H}_u)$。

解码器以目标会话语义 ID 为输入，自回归生成目标。为以合理成本训练更大模型，我们在解码器前馈网络中采用 Transformer 语言模型常用的 MoE 架构［55,9,7］，将第$l$个 FFN 替换为：

$$
\begin{split}
\mathbf{H}_{t}^{l+1} & = \sum_{i=1}^{N_{\rm MoE}} \left( {g_{i,t} \operatorname{FFN}_{i}\left( \mathbf{H}_{t}^{l} \right)} \right) + \mathbf{H}_{t}^{l}, \\
g_{i,t} & = \begin{cases}
s_{i,t}, & s_{i,t} \in \operatorname{Topk} (\{ s_{j, t} | 1 \leq j \leq N \}, K_{\rm MoE}), \\
0, & \text{otherwise},
\end{cases} \\
s_{i,t} & = \operatorname{Softmax}_i \left( {\mathbf{H}_{t}^{l}}^{T} \mathbf{e}_{i}^{l} \right),
\end{split}
\tag{2}
$$

其中$N_{\rm MoE}$为专家总数，$\operatorname{FFN}_{i}(\cdot)$为第$i$个专家 FFN，$g_{i,t}$表示第$i$个专家门值。门值$g_{i,t}$具有稀疏性：$N_{\rm MoE}$个门值中仅$K_{\rm MoE}$个非零，因此每个 Token 只分配给$K_{\rm MoE}$个专家进行计算，保证 MoE 层的计算效率。

训练时，在物品码开头添加起始 Token $\bm{s}_{[\rm BOS]}$，构造解码器输入：

$$
\begin{gathered}
{\mathcal{\bar S}}=\{\bm{s}_{[\rm BOS]},\bm{s}_1^1, \bm{s}_1^2, \cdots, \bm{s}_1^L, \bm{s}_{[\rm BOS]}, \bm{s}_2^1, \bm{s}_2^2,\cdots, \bm{s}_2^L,
\\
\cdots, \bm{s}_{[\rm BOS]},\bm{s}_m^1, \bm{s}_m^2, \cdots, \bm{s}_m^L \}
\end{gathered}
\tag{3}
$$

我们以交叉熵对目标会话语义 ID 做下一 Token 预测（NTP），损失$\mathcal{L}_{\rm NTP}$为：

$$
\begin{gathered}
\mathcal{L}_{\rm NTP} = - \sum_{i=1}^m \sum_{j=1}^L \log P( \bm{s}_{i}^{j+1} \mid [\bm{s}_{[\rm BOS]},\bm{s}_1^1, \bm{s}_1^2, \cdots,  \bm{s}_1^L, \cdots,
\\
\bm{s}_{[\rm BOS]},\bm{s}_i^1,  \cdots,  \bm{s}_i^j ]; \Theta).
\end{gathered}
\tag{4}
$$

经过一定量的会话级列表生成训练，得到种子模型$\mathcal{M}_t$。译注：原式(4)保留；其内层索引从1到L却预测第j+1个码，末项出现未定义的第L+1个码，且未明确首码预测项。不能直接按此索引实现。

### 基于奖励模型的迭代偏好对齐

第3.2节的高质量会话提供训练数据，使模型学习什么是好会话，保证视频生成质量。在此基础上，我们用 DPO 进一步增强模型。传统 NLP 由人类显式标注偏好；推荐系统交互稀疏，给偏好学习带来独特挑战，因此我们引入奖励模型（RM）。第3.3.1节介绍会话级 RM，第3.3.2节介绍允许模型自我改进的迭代直接偏好优化。

算法2：迭代偏好对齐（IPA）

输入响应数 $N$、预训练 $R(\bm u,\mathcal S)$、种子 $\mathcal M_t$、$r_{\mathrm{DPO}}$、总轮数 $T$ 及每轮样本数 $N_{\mathrm{sample}}$。

1. 对 epoch 从 $t$ 到 $T$、sample 从1到 $N_{\mathrm{sample}}$，判断随机数是否小于 $r_{\mathrm{DPO}}$。
2. 若是，以 $\mathcal M_t$ 生成 $N$ 个响应，计算 $r_u^i\gets R(\bm u,\mathcal S_u^i)$；选择 $\mathcal S_u^w=\mathcal S_u^{\arg\max_i r_u^i}$、$\mathcal S_u^l=\mathcal S_u^{\arg\min_i r_u^i}$。
3. 采用 $\mathcal L=\mathcal L_{\mathrm{NTP}}+\lambda\mathcal L_{\mathrm{DPO}}$；否则仅 $\mathcal L=\mathcal L_{\mathrm{NTP}}$。
4. 更新 $\Theta\gets\Theta-\alpha\nabla_\Theta\mathcal L$；轮末更新模型快照 $\mathcal M_{t+1}\gets\mathcal M_t$。

原算法快照赋值未展开更新后参数的归属，保留原符号；正文解释新模型从上轮初始化后更新。

#### 奖励模型训练

以$R(\bm{u},\mathcal{S})$表示为不同用户选择偏好数据的奖励模型；输出$r$表示用户$u$（通常用用户行为表示）对会话$\mathcal{S}=\{\bm{v}_1, \bm{v}_2,\ldots, \bm{v}_m\}$的偏好奖励。
为使 RM 能对会话排序，先为$\mathcal{S}$中的每个物品$\bm{v}_i$提取目标感知表示$\bm{e}_i =  \bm{v}_{i} \odot \bm{u}$。其中$\odot$表示目标感知操作，例如面向用户行为的目标注意力；由此得到会话$\mathcal{S}$的表示$\boldsymbol{h} = \{\bm{e}_1, \bm{e}_2 , \cdots, \bm{e}_m \}$。随后通过自注意力层，让会话内物品交互并融合必要信息：

$$
\begin{aligned}
\boldsymbol{h}_f = \mathrm{SelfAttention}(\boldsymbol{h} \boldsymbol{W}^Q_s, \boldsymbol{h}\ \boldsymbol{W}^K_s, \boldsymbol{h} \boldsymbol{W}^V_s)
\end{aligned}
\tag{5}
$$

接着用不同塔预测多个目标奖励，RM 使用丰富推荐数据预训练：

$$
\small
\begin{split}
\hat{r}^{swt} &= \texttt{Tower}^{swt}\big(\texttt{Sum}\big( \boldsymbol{h}_f  \big)\big),
\hat{r}^{vtr} = \texttt{Tower}^{vtr}\big(\texttt{Sum}\big( \boldsymbol{h}_f  \big)\big),\\
\hat{r}^{wtr} &= \texttt{Tower}^{wtr}\big(\texttt{Sum}\big( \boldsymbol{h}_f  \big)\big),
\hat{r}^{ltr} = \texttt{Tower}^{ltr}\big(\texttt{Sum}\big( \boldsymbol{h}_f  \big)\big), \\
&\texttt{whe}\texttt{re}\quad\texttt{Tower}(\cdot) = \texttt{Sigmoid}\big(\texttt{MLP}(\cdot)\big)
\end{split}
\tag{6}
$$

获得每个会话的奖励估计$\hat{r}^{swt}, \dots$及真实标签$y^{swt}, \dots$后，直接最小化二元交叉熵训练 RM。损失$\mathcal{L}_{\rm RM}$定义为：

$$
\begin{split}
\mathcal{L}_{\rm RM} =-\sum_{{swt,\dots}}^{xtr}\left(y^{xtr}\log{(\hat{r}^{xtr})}+(1 - y^{xtr})\log{(1-\hat{r}^{xtr})}\right)
\end{split}
\tag{7}
$$

#### 迭代偏好对齐

基于预训练 RM $R(\bm{u},\mathcal{S})$与当前 OneRec $\mathcal{M}_t$，我们为每个用户使用 beam search 生成$N$个不同
响应：

$$
\mathcal{S}_u^n \sim M_t(\mathcal{H}_u) \quad \text{for all} \  u \in \mathcal{U} \  \text{and} \  n \in [N],
\tag{8}
$$

其中$[N]$表示$\{1,2,\dots,N\}$。

再用 RM $R(\bm{u},\mathcal{S})$计算每个响应的奖励$r_u^n$：

$$
r_u^n=R(\bm{u},\mathcal{S}_u^n)
\tag{9}
$$

选择最高奖励的胜出响应$(\mathcal{S}_u^w,\mathcal{H}_u)$与最低奖励的落败响应$(\mathcal{S}_u^l,\mathcal{H}_u)$，构成偏好对$D_t^\text{pairs} = (\mathcal{S}_u^w,\mathcal{S}_u^l,\mathcal{H}_u)$。然后用$M_{t}$初始化新模型$M_{t + 1}$，结合 DPO 损失［35］从偏好对学习。每个偏好对的损失为：

$$
\begin{split}
\mathcal{L}_\text{DPO} &=  \mathcal{L}_\text{DPO}( \mathcal{S}_u^w, \mathcal{S}_u^l | \mathcal{H}_u) \\
&=  - \log \sigma \left( \beta \log \frac{ M_{t+1}( \mathcal{S}_u^w | \mathcal{H}_u)}{ M_{t}(\mathcal{S}_u^w  | \mathcal{H}_u)} - \beta \log \frac{ M_{t+1}(\mathcal{S}_u^l| \mathcal{H}_u)}{ M_{t}(\mathcal{S}_u^l| \mathcal{H}_u)}\right).

\end{split}
\tag{10}
$$

如算法2和图2(b)，整体过程训练一系列模型$M_t,\dots,M_T$。为降低 beam search 推理成本，我们仅随机抽取$r_{\rm DPO} = 1\%$的数据做偏好对齐。每个后继模型$M_{t + 1}$从上轮模型$M_{t}$初始化，并使用$M_{t}$生成的偏好数据$D_t^\text{pairs}$训练。

## 系统部署

OneRec 已用于真实工业场景。平衡稳定性与效果，我们部署 OneRec-1B 在线服务。如图3，部署含三个核心部分：训练系统、在线服务系统和 DPO 样本服务器。系统收集交互日志，先用下一 Token 预测目标$\mathcal{L}_{\rm NTP}$训练种子模型；收敛后加入$\mathcal{L}_{\rm DPO}$进行偏好对齐。训练使用 XLA 与 bfloat16 混合精度，优化计算与显存利用。训练参数同步到在线推理模块与 DPO 采样服务器，分别用于实时服务和偏好数据选择。推理采用两项优化：KV cache 解码结合 float16 量化降低 GPU 显存开销；beam size 设为 128，平衡生成质量和延迟。此外，得益于 MoE，推理仅激活 13% 的参数。

## 实验

本节先离线比较 OneRec、逐点方法及多种 DPO 变体，再通过消融检验各模块，最后在快手部署并开展在线 A/B 测试。

### 实验设置

#### 实现细节

模型使用 Adam，初始学习率$2 \times 10^{-4}$，在 NVIDIA A800 GPU 上训练。训练全过程 DPO 样本比例$r_{\text{DPO}}$设为 1%，为每个用户以 beam search 生成$N = 128$个不同响应。语义标识聚类每层有$K=8192$个簇，共$L=3$层；MoE 有$N_{\text{MoE}}=24$个专家，每次前向通过 top-$k$选择激活$K_{\text{MoE}}=2$个。会话建模使用$m=5$个目标物品及$n=256$条历史行为作为上下文。

#### 基线方法

我们选择下列代表性推荐模型、DPO 及其变体作为基线：

-  **SASRec** ［22］ 使用单向 Transformer 捕捉用户—物品交互的序列依赖，预测下一物品。

-  **BERT4Rec** ［40］ 使用双向 Transformer 和掩码语言建模，通过序列重建学习上下文化物品表示。

-  **FDSA** ［50］ 以双自注意力路径联合建模物品转移和异构特征变换模式。

-  **TIGER** ［36］ 结合层次语义标识与生成式检索，通过自回归序列生成完成序列推荐。

-  **DPO** ［35］ 通过隐式奖励建模，以从人类反馈推导的闭式奖励函数形式化偏好优化。

-  **IPO** ［1］ 提出具有理论依据的偏好优化框架，绕过标准 DPO 的近似。

-  **cDPO** ［30］ 通过标签翻转率参数 $\epsilon $ 考虑偏好标注噪声。

-  **rDPO** ［5］ 利用重要性采样构造无偏损失估计，减少偏好优化的方差。

-  **CPO** ［47］ 联合训练序列似然奖励与监督微调目标，统一对比学习和偏好优化。

-  **simPO** ［29］ 以序列奖励边界开展偏好优化，通过归一化概率平均消除对参考模型的依赖。

-  **S-DPO** ［4］ 以困难负采样和多物品对比学习将 DPO 适配到推荐，提高排序准确性。

#### 评估指标

我们使用多个指标评估输出的不同方面，每轮从随机抽取的测试案例上评估。用预训练奖励模型估计特定用户—会话对的交互概率，并评估推荐会话的价值。计算不同目标的平均奖励，包括会话观看时长（**swt**）、观看概率（**vtr**）、关注概率（**wtr**）和点赞概率（**ltr**）；swt、vtr 属于观看时长指标，wtr、ltr 属于交互指标。

**第一，会话级生成显著优于传统点积方法和 TIGER 等逐点生成方法。**OneRec-1B 的最大 swt 比 TIGER-1B 高 1.78%，最大 ltr 高 3.36%。作者认为，这体现会话级建模保持推荐上下文连贯性的优势，而逐点方法难以兼顾连贯性与多样性。译注：表1对应值为 .1529 对 .1368、.0660 对 .0579；相对增幅约为 11.77% 和 13.99%，与原文百分比不一致。原话与表值均保留。

**第三，IPA 优于多种已有 DPO 变体。**如表1，IPA 比替代 DPO 实现获得更好效果。有些 DPO 基线甚至低于未对齐的 OneRec-1B，表明迭代挖掘自身生成输出并选择偏好数据比这些方法更有效。

### 消融研究

#### DPO 样本比例消融

在控制条件下，将 DPO 比例 $r_{\rm DPO}$ 从 1% 提高到 5%。如图4，多个评估目标的改善较小。尽管计算开销增加，相对 1% 基线的提升仍不显著。DPO 样本服务器推理的 GPU 资源随采样比例线性增加：5% 比例需要 1% 的 $5 \times$ GPU 资源。因此综合计算效率与效果后采用 1%；作者报告它平均达到最大观测性能的 95%，而仅需更高比例所需资源的 20%。

#### 模型规模消融

图6显示，OneRec 从 0.05B 扩大到 1B，准确性持续改善。具体而言，0.1B 相比 0.05B 的准确性最大增益为 14.45%；继续扩至 0.2B、0.5B、1B，分别获得 5.09%、5.70%、5.69% 的额外增益。

### OneRec 的预测动态

如图5，我们展示不同层 8192 个码的预测概率分布，红星表示奖励最高物品的语义 ID。相比 OneRec 基线，OneRec+IPA 的预测置信分布发生明显偏移，说明偏好对齐鼓励模型产生偏好的生成模式。此外，第一层分布更分散（熵为 6.00），第二层平均熵为 3.71，第三层熵为 0.048，逐层趋于集中。作者将这种不确定性下降归因于自回归解码：初始层继承前序解码的不确定性，后续层利用累积上下文约束决策空间。

### 在线 A/B 测试

为评估线上效果，我们在快手主页面视频推荐中开展严格 A/B 测试，以 1% 主流量比较 OneRec 与现有多阶段推荐系统。总观看时长衡量用户观看视频的总时间；平均播放时长衡量用户曝光于请求会话时每个视频的平均观看时间。线上结果中，总观看时长提升**1.68%**，平均播放时长提升**6.56%**，作者认为这说明推荐效果显著改善，并给平台带来可观收入增量。译注：本节未报告收入指标，观看指标不能单独证明收入增量；表2标题的“绝对提升”也未披露百分比基数。

## 结论

本文介绍工业单阶段生成式推荐方案。首先，通过 MoE 高效扩大参数量，为大规模工业推荐提供可扩展蓝图；其次，发现会话级目标物品上下文建模的重要性，认为其比孤立逐点建模更能刻画用户偏好动态；再次，以迭代偏好对齐（IPA）提高模型对多样用户偏好的泛化。离线与在线 A/B 实验验证了 OneRec 的效果与效率。同时，线上结果表明，除观看时长外，模型在点赞等交互指标上仍有限制。未来将增强端到端生成式推荐的多目标建模，以改善用户体验。
