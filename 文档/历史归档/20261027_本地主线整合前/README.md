# 推荐大模型 · 个人知识库

围绕推荐、搜索与营销补贴系统，持续把资料与问答编译为可回查、可修订的知识。传统与生成式方法共用模块和问题主干，营销补贴从因果增量、成本与预算策略接入。主要通过 Codex / Claude Code + Markdown 使用，按需用 Obsidian 浏览。

日常直接给一篇论文（链接、ID、PDF 或题名），Agent 默认完成 **翻译 → 精读笔记 → 核心知识提炼 → 相关问题与方法比较**，保存结果、核对译文并维护双向引用。后续论文统一沿用 ESMM 已跑通的[标准流程](维护/工作流.md#论文知识沉淀标准流程)，无需指定目录、填写元数据或逐阶段确认。只想翻译/解答时说明即可。

学习从 [推荐系统总图](知识库/总览/推荐系统总图.md) 或自动 [知识地图](知识库/知识地图.md) 进入：**模块 → 问题 → 有哪些解法、差别与条件 → 对应论文精读**。已建立14个推荐模块与[4个搜索模块](知识库/总览/搜索系统总图.md)、[生成式跨模块专题](知识库/总览/生成式推荐专题.md)与 [58 篇论文阅读线索](知识库/阅读/候选论文.md)（首批38篇，新增15篇搜推候选与5篇Transformer基础候选；其中9篇搜索论文已核对摘要并拆解模块问题，待全文精读）。查资料依据进入 [来源目录](来源/来源目录.md)。首批38篇均已有中文PDF、精读与问题比较：2026-10-26补齐原缺的25篇PDF，并恢复YouTube DNN、DIN、MMoE、Herlocker评估综述和On Sampled Metrics五篇原文的完整学习流程。本轮30份中文PDF共311页，均已逐页渲染目视；BPR、PLE、DFM及无源码的恢复项采用重排工程，具体翻译范围和英文保留部分见各阅读笔记。[全部交付与检查](文档/会话/PAPER-001.md)；[Herlocker中文PDF与精读入口](来源/SRC-HERLOCKER-EVAL/阅读笔记.md)。

首篇已完成论文为 [ESMM](来源/SRC-ESMM/阅读笔记.md)，从 [点击后转化率估计](知识库/问题/点击后转化率估计.md) 比较点击样本直接训练、概率相除与全空间多任务方案。

知识页与精读笔记写成面向人的技术文章，重点讲清问题、原理、具体解法和方法异同；引用随结论给出，维护记录留在元数据与交接中。

阅读目录、文件名、模块与章节标题优先中文，例如“知识库/模块/召回与检索.md”“知识库/阅读/经典论文路线.md”。论文与模型名、稳定 ID 和工具约定入口保留原文，见 [命名约定](SCHEMA.md#知识页)。

```mermaid
flowchart LR
    P[给一篇论文] --> T[翻译与原文对照]
    T --> N[精读笔记：问题、解法、证据]
    N --> W[模块中的问题与方案比较]
    W --> Q[按问题学习，回查论文]
    Q -->|新理解与纠错| W
```

知识正文的唯一归属是 `知识库/`；来源身份、版本和阅读笔记在 `来源/<来源ID>/`；规则、路由和审核在 `维护/`；任务与交接记录执行状态。根记忆只保留当前事实及入口，不复制知识正文。目录按实际知识生长，不预建几十个空栏目。

```bash
python3 scripts/wiki.py search "增量摄入"
python3 scripts/wiki.py plan
python3 scripts/wiki.py lint --local
python3 scripts/check_context.py
```

工具只用 Python 3 标准库；它登记、检索和检查，不调用模型或自动判定论文真伪。完整命令、原件恢复及验收见 [工具说明](scripts/README.md)。本仓库仅本地 Git；默认自查后用中文提交明确文件。原件快照在忽略的 `.local/sources/`，需要单独备份，Git 中的哈希不能代替原件。
