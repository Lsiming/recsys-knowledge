# 推荐大模型

围绕传统推荐、营销补贴和生成式推荐建设个人知识库，支持前沿论文调研、算法学习和知识沉淀，按需要开展复现实验。当前已具备上下文规范和知识库设计提案，尚无推荐算法实现或实验结果。

## 从这里开始

新会话先读 [AGENTS.md](AGENTS.md)，再读 [当前记忆](PROJECT_MEMORY.md)、[总交接](SESSION.md) 和 [任务队列](TODO.md)，按任务进入专题。完整文档导航见 [docs/README.md](docs/README.md)。

## 日常使用

- 开始论文调研：使用 [论文笔记模板](docs/模板/论文笔记模板.md)，笔记放在 `docs/研究/<主题>/` 并登记 [研究索引](docs/研究/README.md)。
- 开始复现实验：使用 [实验记录模板](docs/模板/实验记录模板.md)，记录放在 `docs/实验/<实验ID>/` 并登记 [实验索引](docs/实验/README.md)。
- 开一个并行会话：先登记 TODO 中的任务和写入范围，再使用 [任务交接模板](docs/模板/任务交接模板.md) 建立独立交接文件。总交接由当轮明确的整合会话合并更新。
- 恢复旧任务：读取任务交接中的证据与下一条动作，核对当前 Git 和最新用户指令后继续。

知识库覆盖传统推荐、营销补贴、生成式推荐，具体首轮问题和资料优先级尚未确定。建议架构与现有能力的区别见 [知识库设计](docs/治理/20261025_推荐系统知识库设计/README.md)；长期范围见 [项目背景](docs/PROJECT_BACKGROUND.md)。

## 本地运行与维护

文档可直接阅读。上下文检查只依赖本机 Python 3 标准库，无需安装依赖；模型实验的环境和命令在各实验中记录，目前没有统一训练入口。

```bash
python3 scripts/check_context.py
git diff --check
git status --short --branch
git log -5 --oneline
```

本仓库仅维护本地 Git。完成修改并验证后默认提交本任务明确文件，提交信息使用中文；用户明确不提交时遵从。多会话的分支合并规则见 [协作规范](docs/规范/上下文与多会话协作.md)。

`logs/`、`data/`、`outputs/`、权重、缓存、凭证及本地环境不入 Git；实验结论、配置说明和可公开的汇总图表可以入 Git。论文原始 PDF 默认放 `papers/`，笔记保留原文链接和版本。
