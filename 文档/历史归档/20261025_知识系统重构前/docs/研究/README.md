# 研究索引

当前尚无论文条目或已验证研究结论。首次调研明确主题后在此登记；下表是字段定义，不是待执行论文清单。

| 字段 | 内容 |
|---|---|
| 主题 / 论文 | 简短名称与所属任务 ID |
| 笔记入口 | 主题目录中的相对链接 |
| 原始来源 | 原论文/官方代码 URL 与版本 |
| 阅读状态 | 待读 / 摘要已读 / 全文已读 / 分析完成 / 已复现 |
| 当前结论 | 证据层级、适用条件与尚缺证据 |
| 更新日期 | 最近一次实质更新日期 |

新增笔记使用 [论文模板](../模板/论文笔记模板.md)，遵守 [研究工作流](../规范/研究工作流.md)。索引由整合会话维护，专题会话在独立交接提交待合并条目。
