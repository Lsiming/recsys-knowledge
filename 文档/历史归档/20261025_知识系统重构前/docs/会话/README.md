# 任务交接目录

每份交接对应一个稳定任务 ID，可由后续会话接手，不要求绑定永久聊天 ID。有效任务状态以 [TODO](../../TODO.md) 为准，总主线见 [SESSION](../../SESSION.md)。

| 任务 | 入口 | 说明 |
|---|---|---|
| CTX-001 | [上下文系统初始化](CTX-001.md) | 初始设计、实际检查和后续入口 |
| KB-001 | [推荐系统个人知识库设计](KB-001.md) | 首轮提案已交付；后续系统设计迭代的状态、阅读路由与讨论入口 |
| TOOL-001 | [GitHub MCP 与 CLI](TOOL-001.md) | 用户级安装、账户认证、客户端配置与实际连接验证 |

新增任务用 [任务交接模板](../模板/任务交接模板.md)。专题会话可写自己的交接文件；此索引、TODO 和根上下文由整合会话更新。
