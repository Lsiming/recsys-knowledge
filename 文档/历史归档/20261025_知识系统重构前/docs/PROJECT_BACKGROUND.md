# 项目背景

本页描述长期目标与边界；当前事实见 [PROJECT_MEMORY](../PROJECT_MEMORY.md)，执行规则见 [AGENTS](../AGENTS.md)。

## 已确认的目标

2026-10-13 用户明确：本仓库主要用于调研学习推荐和交易场景的前沿模型，只做本地 Git 维护，并参考既有项目的上下文管理与多会话协作方式建立可持续工作体系。

2026-10-25 用户进一步明确：希望将本仓库建设为关于推荐系统的个人知识库，覆盖传统推荐、营销补贴、生成式推荐等方向，能够保存论文、解读、源码，并基于资料持续形成系统化知识，服务前沿论文调研、算法学习和知识沉淀。

产出形式包括来源登记、论文笔记、概念与方法知识、专题比较、学习路径、研究问题与适用性分析，以及按需要开展的最小复现实验。当前已形成 [知识库设计提案](治理/20261025_推荐系统知识库设计/README.md)，具体首轮题目和完整实施尚未启动。

## 范围与候选方向

传统推荐可围绕召回/排序/重排、特征与序列建模、多任务与评估；营销补贴可围绕响应与增量效果、预算约束和策略优化；生成式推荐可围绕物品表示、生成目标、解码与效率。具体知识地图属于设计建议，尚未进行对应的系统文献检索，也未确定优先级。

初始化中未限定的“交易”不再作为必须先澄清的总前提，当前按用户新明确的三领域推进设计。各方向的具体业务场景，以及是否扩展其他交易问题，仍随具体任务明确，不从参考项目继承业务假设。

## 研究边界

- 论文报告效果、本地复现效果、业务适用性分别表达，保留信息不足和失败结果。
- 不预设数据源、业务指标、模型基准和可用计算资源；各实验记录自身协议。
- 当前没有生产模型发布目标或统一训练平台。后续若扩展，先更新目标与相应执行约定。
- 参考项目用于学习知识组织、上下文与维护机制；其字段、路径、业务假设、模型效果及远端工作流不迁入本项目。

## 后续任务中需明确

1. 第一个要回答的研究问题及所属的传统推荐、营销补贴或生成式推荐场景。
2. 首批论文/官方代码、时间范围，以及希望达到的学习深度。
3. 交付偏重解读、横向比较还是代码复现；若需复现，再明确数据、环境和资源。

知识库设计参考与固定来源见 [参考研究](治理/20261025_推荐系统知识库设计/01_参考资料研究.md)。尚无推荐算法论文条目或真实实验结果；领域资料到位后进入 [研究索引](研究/README.md)，不要把未验证内容直接升级为项目事实。
