新专题使用 `docs/研究/<中文主题>/`；独立实验使用 `docs/实验/<实验ID>/`。小型汇总图片/表格放所属目录 `assets/`，真实样本、权重和原始运行日志放忽略目录。新增或移动文档时同步相关索引和相对链接。

根目录 [README](../README.md) 是人类入口，[AGENTS](../AGENTS.md) 是 Agent 入口。各索引和根上下文由整合会话合并维护，专题会话只编辑已认领范围。
