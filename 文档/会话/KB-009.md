换设备下载需要Python 3.9+、GitHub CLI以及有权访问仓库的账号：

```bash
gh auth login
gh repo clone Lsiming/recsys-knowledge-attachments
cd recsys-knowledge-attachments
python3 download.py
```

PDF默认保存到私有克隆内的`.local/pdfs/<来源ID>/`。后续先`git pull --ff-only`，再运行下载器；支持`--source`、`--dest`、`--verify-only`和1至4个并发。`git clone`/`git pull`本身不会下载Releases附件。联网前检查仓库仍为私有，凭证由gh管理；临时下载校验通过后原子替换，失败保留旧文件，CLI可能包含临时签名URL的错误信息不输出。
