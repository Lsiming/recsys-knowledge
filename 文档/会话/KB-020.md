## 单正式版与核验临时件

本地用来源卡登记的采用版快照保存原文字节，既有查阅路径可用相对符号链接。译文沿用现有有效入口。93 篇各保留一份原文、一份中文 PDF，逐份核对完整哈希、PDF 类型及页数。按已登记哈希清理 211 份重复或被替代的物理附件，其中 100 个旧查阅路径转为相对符号链接。清理已完成批次的 55 份下载尝试、验证片段及废弃候选。两项共释放 503,800,059 字节。译后工程依赖、独有来源资料和校验文字收据保留。41 篇本地沿用已验收的清理或加封面前版本，分别按本地和私有登记核对。

私有目录原有 186 条正式记录。实际 Release API 多出一份 OneReason 原文，与登记资产和本地采用版完整 SHA-256、大小一致。只撤下这份额外资产。重新对账 20 个 Releases 的 186 份 PDF，确认目录与实际资产的标签、文件名、状态、大小和 digest 一致。私有工具提交为 `c503eb4`。新工具用固定文件名保存正式下载，校验通过后收拢此前工具生成的同类型版本文件。已登记复验和新候选验证均实际登录下载至临时目录，返回时自动清理。以 FTRL 原文与译文执行真实复验，再走一次译文候选验证，确认三次下载的完整哈希和验证目录清空。失败、哈希不符、超时和旧文件保留路径通过隔离测试。

## 从第 05–06 批反查知识

以十篇论文、固定版本、来源 ID 和方法别名搜索全库。初始定位 10 个直接绑定页、7 个正文或导航提及页、49 个相关页和 16 篇其他阅读笔记。优先复核涉及结论的语句和学习入口，并按覆盖、有效性和冲突复读原文。CL4SRec v2 §4.1.2 和 CoSeRec v1 §5.1.2 都明确以全物品集合评估，CL4SRec 还明示过滤已交互项。原先[自监督视图问题](../../知识库/问题/推荐自监督怎样构造有效视图.md)的“受采样影响”表述已校准，并用两篇主损失式区分训练时的 sampled softmax 与逐项 sigmoid。两篇笔记同步修正并补序列模块入口。PinSage v1 §3.3 的共享随机负例与逐轮图难负例已进入[召回负样本问题](../../知识库/问题/负样本怎样改变双塔召回目标.md)。FTRL 印式与算法差异按目标展开核对。物品自监督表 7、CoSeRec 表 3–4 的原文内部疑点仍留[审核台](../../维护/审核台.md)，相应数值限定在可证范围内使用。

重跑整合、索引、题名/来源 ID/问题检索、全库结构与原件检查。定向回查支撑了受影响结论的修订，本轮未复跑论文实验。公开知识库发布范围包括已经完成的第 05–06 批本地提交和本次流程增量。
