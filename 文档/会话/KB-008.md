## 工具与持续流程

克隆或 `git pull` 不会自动下载 Releases 附件。Python 3.9+ 标准库工具 `python3 scripts/download_translations.py` 批量下载已许可资产；支持逐篇选择、指定目录、仅校验本地、跳过正确文件。下载检查 PDF 类型、大小、SHA256，用临时文件及原子替换，失败不破坏原文件，逐篇报告并返回失败状态。

新增 `pdf_releases.py` 离线校验与生成目录，`prepare_pdf_release.py` 用可选 pypdf/reportlab 和可嵌入中文字体准备署名副本。规则、契约、工作流、贡献指南、许可与论文模板已同步，后续新论文同样逐篇处理。持续授权仅包含允许公开的中文 PDF 及配套目录/入口，不扩展为推送其他会话的未完成知识。

8 篇已有公开阅读笔记追加实际下载入口与后续状态，保留当次编译/本地记录；相应整合收据保留原科学内容自查，明确本轮仅导航与附件核查。On Sampled Metrics 等6篇尚无公开来源卡的附件仅作盘点登记，不导入其在另会话的笔记或暗示精读已合入。原件和旧私人 Git 历史均未推送。
