# 实验索引

当前无模型实验、基准或运行结果。新增实验以稳定实验 ID 建目录，不把目录日期当作运行身份。

| 字段 | 内容 |
|---|---|
| 实验 ID / 任务 ID | 唯一标识与上游研究任务 |
| 目标与基准 | 本轮问题及对照版本 |
| 记录入口 | 所属目录的协议与真实结果链接 |
| 运行状态 | 方案 / 运行中 / 失败 / 已完成 / 无结论 |
| 源码与输入身份 | Git 基线、实际变更、数据/配置版本入口 |
| 当前结论 | 实际指标、证据限制与下一步 |

使用 [实验模板](../模板/实验记录模板.md)。索引由整合会话维护；真实数据、权重和日志留忽略目录，报告记录位置及保留条件。
