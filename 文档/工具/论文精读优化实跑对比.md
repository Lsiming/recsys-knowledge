## 这次改变的不是简单把文字写长

| 学习时要走的台阶 | 旧稿怎样写 | 新稿怎样补上 |
|---|---|---|
| GPT到BERT为何要改目标 | 说明双向性、复制风险与MLM | 先跑GPT前缀预测，再解释解除因果限制为何会复制；同一行的下一词与同位置恢复并排比较 |
| 原文怎么变成监督 | 一句“我买了MASK，装上镜头”解释右文线索 | 一条相邻文本对，逐位置列原词、损坏输入、片段和标签，跟踪4/9两行；不冒充真实WordPiece |
| 三种Mask有什么区别 | 已区分MASK符号和Attention Mask | 新图同时显示输入替换、Key可见性和loss位置；解释PAD、随机词、原样分支与跨片段可见 |
| Hidden State究竟是什么 | 用$C,T_i$命名状态，未完整走轴与读出 | 输入三向量相加→$[1,12,d]$每位置状态→选4/9或CLS→词表/关系两种输出轴 |
| loss怎么算出来 | 有MLM求和式及预训练两均值描述 | 真值概率0.7/0.5→逐项负对数→MLM均值0.5249，再加NSP0.2231；区别求和与平均 |
| 未计loss的位置学不学 | 没有本篇对应路径 | 两行真类梯度-0.15/-0.25，再解释沿上下文回到较低层和共享骨干，不复制公共完整推导 |
| 训练完怎样用 | 分类、NER、QA、SWAG已覆盖 | 加阶段表，指出换的是类别/词标签/输入位置/候选的输出轴；微调继承参数而非MLM预测值 |
| 复习与看图 | 无正文嵌入图 | 顶部直达样本、Mask、loss、梯度、使用；两幅中文机制图可直接显示，公共页复用相同实体 |

例如，旧稿“每位置输入是Token、片段类型A/B和位置Embedding之和”是正确但压缩的描述。新稿进一步指出三项都是$d$维而非拼成$3d$维；位置4查MASK向量，原词留在标签侧；输出仍有12行，MLM选4/9，NSP选0。读者可以沿一个具体位置追到下一步，而不是只记住三个Embedding名称。

旧稿实验与局限部分没有为腾空间而删掉：数据/预算、主表口径、消融混杂、负面例外、推荐映射和既有译文范围原字节保留；技术主线另行扩写。旧稿也有许多正确的细节，本次不把它描述为只有摘要或存在全面事实错误。
