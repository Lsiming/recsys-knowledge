## 参考仓库分析

用户指定的低价固价模型 V2 仓库仅作为只读设计参考。阅读根 AGENTS、README、PROJECT_MEMORY、SESSION、TODO、docs/PROJECT_BACKGROUND、docs/README、docs/规范/迭代工作流，以及工作流/目录治理相关记录；未修改参考仓库。

其上下文设计有以下特征：

- AGENTS 统一入口，CLAUDE 只转向；新会话通过 Git 状态、根上下文和相关契约恢复工作。
- README 导航、背景写长期边界、MEMORY 保存有效事实与决定、SESSION 保留最新交接、TODO 保存有效待办；长报告与历史另存。
- 按独立研究问题聚合方案、结果、验收与附件，索引链接证据；大幅压缩前保留历史原文。
- 并发优先分支/worktree、共享文档由主会话整合；写回和提交前重查并发增量，按文件/hunk 提交。
- 运行身份和真实验证单独记录，计划、文档和历史停点不代替实际证据或当前指令。

这是对文档约定及治理记录的分析，并非对参考仓库并发机制或模型效果进行运行验收。
