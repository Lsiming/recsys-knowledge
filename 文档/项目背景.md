# 项目背景

本页描述长期目标与边界；当前事实见 [PROJECT_MEMORY](../PROJECT_MEMORY.md)，执行规则见 [AGENTS](../AGENTS.md)。

## 已确认的目标

2026-10-13 用户明确：本仓库主要用于调研学习推荐和交易场景的前沿模型，只做本地 Git 维护，并参考既有项目的上下文管理与多会话协作方式建立可持续工作体系。

2026-10-25 用户进一步明确：希望将本仓库建设为关于推荐系统的个人知识库，覆盖传统推荐、营销补贴、生成式推荐等方向，能够保存论文、解读、源码，并基于资料持续形成系统化知识，服务前沿论文调研、算法学习和知识沉淀。

日常维护应简单高效：用户给一篇论文，即完成翻译、精读笔记和核心知识提炼，把解决的问题、具体解法及与已有方法的异同沉淀到对应模块。学习时可沿“模块 → 问题 → 解法 → 论文”快速展开。知识页与精读笔记采用面向人的技术文章风格，少写无关描述和执行状态。

面向阅读的目录、文件名、模块及章节标题尽量使用中文；论文题名、模型名、稳定 ID 与工具约定入口保留必要原文，方便检索与技术核对。

用户已明确后续从各模块经典论文着手学习和沉淀。[经典阅读路线](../知识库/阅读/经典论文路线.md)先标经典基础，再接代表/进阶与较新的生成式路线；每次由用户指定论文后执行标准流程，框架与候选清单不代替真实精读。

产出形式包括来源登记、论文笔记、概念与方法知识、专题比较、学习路径、研究问题与适用性分析，以及按需要开展的最小复现实验。2026-10-25 用户授权按合适方式重构，已落实 [来源目录](../来源/来源目录.md)、[持久知识层](../知识库/知识地图.md)、[知识契约](../SCHEMA.md) 和本地维护工具；前期 [知识库设计提案](治理/20261025_推荐系统知识库设计/目录.md) 保留为历史依据。随后用户授权先搭领域框架、梳理论文候选，后续再逐篇指定标准学习流程。

2026-10-26 用户明确将搜索作为新增学习方向：先依据选定9篇论文摘要，拆出现有模块和问题未覆盖的内容，后续再逐篇按标准流程精读。已建立[搜索总图](../知识库/总览/搜索系统总图.md)及查询理解、改写规划、联想补全、相关性判断4个模块；端到端召排、训练、解码、评估和服务复用已有主干。摘要框架与全文精读分开，不据摘要补造实现或实验结论。

## 2026-10-26：公开共建

2026-10-27 用户补充授权：现有与后续新论文的中文 PDF 按逐篇许可发布到 GitHub Releases，仓库维护版本、翻译范围、下载入口及一键下载工具。未获许可或失败的逐篇报告；PDF 二进制仍不进入 Git 历史。具体见[发布流程](工具/中文PDF发布.md)。

## 范围与候选方向

传统与生成式推荐采用统一的 [模块与问题主干](../知识库/总览/推荐系统总图.md)，覆盖数据、表征、召回/粗排/精排/重排、兴趣序列、多任务、多场景、训练、生成解码、评估、服务与长期决策。生成式作为 [跨模块专题](../知识库/总览/生成式推荐专题.md)，既容纳局部新解法，也讨论多个阶段的联合改变，不另建重复百科。

首轮框架依据九份固定版本 GitHub 资料的指定 README 范围做定向梳理，形成 [候选论文](../知识库/阅读/候选论文.md)与 [资源导读](../知识库/总览/学习资源导读.md)，不是完整文献综述或效果排序。营销补贴继续作为相关应用范围，从响应与因果增量、预算约束、探索和策略问题接入；专门文献尚待补齐。初始化中未限定的“交易”不设为前置澄清，各业务定义随具体任务明确，不从参考项目继承假设。

## 研究边界

- 论文报告效果、本地复现效果、业务适用性分别表达，保留信息不足和失败结果。
- 不预设数据源、业务指标、模型基准和可用计算资源；各实验记录自身协议。
- 当前没有生产模型发布目标或统一训练平台。后续若扩展，先更新目标与相应执行约定。
- 参考项目用于学习知识组织、上下文与维护机制；其字段、路径、业务假设、模型效果及远端工作流不迁入本项目。

## 资料与实验如何开始

给出论文即按默认学习流程处理，模块归属随内容确定；常规单篇无需提前注册任务或逐阶段确认。开放调研再明确问题与检索范围，模型实验另行确定数据、环境、资源及评估协议，不把这些未知项设为论文阅读的门槛。

知识库设计参考与固定来源见 [参考研究](治理/20261025_推荐系统知识库设计/01_参考资料研究.md)，领域框架的依据见 [资源导读](../知识库/总览/学习资源导读.md)。目前已有领域模块、阅读线索与 [ESMM 首篇精读](../来源/SRC-ESMM/阅读笔记.md)，并沉淀为 [点击后转化率问题](../知识库/问题/点击后转化率估计.md)。该篇完成源码翻译、中文 PDF 与问题方案比较；其余线索不冒充已读论文证据，尚无本仓库模型实验或业务收益验证。
