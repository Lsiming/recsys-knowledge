# 工具环境约定

- Python：3.9+，标准库。来源日期默认 Asia/Shanghai；已发生事实用显式检索日期记录。
- 仓库根：由 scripts/wiki.py 的位置推导，不硬编码用户路径；`--root` 可用于独立临时验收。
- 本地原件：`.local/sources/<来源ID>/<sha256>/<原文件名>`；目录忽略且需另备份。
- 来源地址/版本：逐条存储在 来源目录的 JSON，不在工具中硬编码。当前本地 skill 的恢复提示在其来源笔记中。
- 签名：SHA256；处理语义签名由 SCHEMA.md 的“处理语义版本”生成。实质提取/证据/合并规则改变才升版，普通目录/排版/工具重构不触发全库重处理；阅读笔记、来源版本和引用绑定仍会被检查。
- 索引：知识库/知识地图.md、来源/来源目录.md；语义正文才是输入，索引不要手工编辑。type=map + module 标识唯一模块导读，无 module 的 map 为总览/专题/阅读路线；problem 的 solutions 只接已登记 paper 来源。
- 译文：许可已确认的正式 Markdown 在 `译文/<来源ID>/中文译文.md`；PDF、工作版/未授权 Markdown 和译后工程在 `.local/papers/<来源ID>/translation/`。均为派生材料，不充当独立外部证据；公开元数据见 `译文/目录.json`。
- PDF附件：原文和中文PDF在独立私有附件库Releases维护，私有Git的附件目录按来源ID/类型/哈希分版本；原文保持原字节，公开源卡的快照哈希不改。普通克隆/CI不需要私有权限。
- 并发：没有程序锁；遵守任务范围与串行写入约定。允许 GitHub remote；不自动推送，不保存外部凭证。公共 CI 不联网获取论文，不要求原件。
