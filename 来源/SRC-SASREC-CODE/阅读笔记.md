# SASRec官方实现：位置、归一化与采样怎样落到代码

[论文笔记](../SRC-SASREC/阅读笔记.md) · [学习思考](../SRC-SASREC/学习思考.md)

固定作者仓库commit为[e3738967fddab206d6eeb4fda433e7a7034dd8b1](https://github.com/kang205/SASRec/tree/e3738967fddab206d6eeb4fda433e7a7034dd8b1)，本页静态读取TensorFlow实现；没有安装旧运行环境、训练模型或运行其评估。论文的概括公式与这份脚本有差异，应分别说明，不能把它们合写成一套完全一致的计算图。

## 共享物品表与窗口位置表

[model.py第15–46行](https://github.com/kang205/SASRec/blob/e3738967fddab206d6eeb4fda433e7a7034dd8b1/model.py#L15)调用同一个物品表，0号PAD行置零，输入查表结果乘$\sqrt d$；输出查表使用返回的未缩放表。位置ID由range(maxlen)产生，再沿batch轴tile，没有用户ID维度。位置表不乘$\sqrt d$；两种嵌入相加后做输入Dropout，再按非零物品ID清零填充行。因此此代码的有效输入是$\sqrt d M_{s_t}+P_t$，而论文式(1)写$M_{s_t}+P_t$。

self.u虽然存在于占位符和predict参数中，后续打分计算没有读取它，也没有独立用户Embedding；个性化来自实际历史。位置表和物品表是不同变量；所谓共享位置，是所有样本在同一窗口槽位查同一行，不是所有槽位共用一个向量。

## 归一化路径与论文概括式不同

[model.py第50–68行](https://github.com/kang205/SASRec/blob/e3738967fddab206d6eeb4fda433e7a7034dd8b1/model.py#L50)传入queries=normalize(self.seq)、keys=self.seq。结合[modules.py的multihead_attention](https://github.com/kang205/SASRec/blob/e3738967fddab206d6eeb4fda433e7a7034dd8b1/modules.py#L160)，忽略Dropout但保留仿射偏置，可记为：

$$U=LN_a(X),\quad Q=UW_Q+b_Q,\quad K=XW_K+b_K,\quad V=XW_V+b_V,$$
$$A=softmax(QK^\top/\sqrt{d_k}+C),\quad Y=U+\operatorname{ConcatHeads}(AV).$$

注意力残差加的是传入的queries即$U$，不是未归一化的$X$；这个函数拼头后未再加一个$W_O$。训练Dropout施加在注意力概率上，然后乘V，不是在该函数末端对整段Attention输出做Dropout。代码有填充Key与Query处理，上式只描述有效查询的核心。

接着令$T=LN_f(Y)$，feedforward(T)为

$$R=Dropout(ReLU(TW_1+b_1)),\quad Z=T+Dropout(RW_2+b_2).$$

两次conv1d(kernel_size=1)只混合特征，不跨位置；调用传入[d,d]，所以是$d\to d\to d$，不等于原Transformer的$d\to4d\to d$。残差同样加的是已归一化$T$。每个block后清零PAD行，全部block后另有final LN。不能用标准Pre-LN的$I+J_fJ_{LN}$直接代表这份脚本：以注意力分支为例，恒等支路是相对$U$，相对原始$X$仍经过$J_{LN_a}$，K/V还另从X进入。

论文§III-C写的是$X+Dropout(g(LN(X)))$；它可与原Transformer的Post-LN比较，但不能据此声称该固定代码严格逐算子实现了此概括式。上述差别来自静态计算图，不是训练效果或论文结果有误的证据。

## 填充遮罩与末位置切片

modules.py依据keys的绝对值和判断Key是否非零，将无效Key分数改成$-2^{32}+1$；下三角因果遮罩保留对角线。Softmax后按传入queries的非零性清理查询，再做概率Dropout。它用有限大负数，不能照搬成“全为负无穷的Softmax仍正常”；Query来自LN，带可学习beta，故Query非零检测也不能被当作普遍可靠的ID mask。外层每块的ID mask仍会清零PAD输出。

[model.py第76–80行](https://github.com/kang205/SASRec/blob/e3738967fddab206d6eeb4fda433e7a7034dd8b1/model.py#L76)的测试候选占位符固定为101个：先给所有窗口行算101候选分数，reshape为$[B,n,101]$后才切最后一行。由于输入左填充，最后数组行就是有效历史末行（非空历史前提）。数学上可先取末状态再乘候选表以省重复打分，但这份代码没有这样重排，更没有全目录ANN或KV Cache实现。

## 训练负例与损失归约

[sampler.py](https://github.com/kang205/SASRec/blob/e3738967fddab206d6eeb4fda433e7a7034dd8b1/sampler.py#L13)每次抽取至少有两次训练行为的用户，从训练序列末端倒填seq与pos。random_neq均匀抽物品ID并拒绝该用户**整个训练序列**中的物品；不是只排除当前前缀，不排除未纳入train集合的验证/测试物品。不同位置负例允许重复；当物品全集都已被该用户训练序列覆盖时，拒绝循环无法结束，正常采样须有可选负物品。

[model.py第82–104行](https://github.com/kang205/SASRec/blob/e3738967fddab206d6eeb4fda433e7a7034dd8b1/model.py#L82)分别对正负内积算sigmoid BCE，用pos!=0筛目标，对整个batch的有效目标数归一化，再加Embedding正则项，交给Adam。代码用sigmoid加微小常数后取log；正文的softplus等价式用于解释理想数据目标，不代表它已经采用融合的稳定BCE算子。空有效目标需避免零分母。

## 101候选评估与论文未披露部分

[util.py的evaluate](https://github.com/kang205/SASRec/blob/e3738967fddab206d6eeb4fda433e7a7034dd8b1/util.py#L42)把验证行为接到测试历史，再抽100负例；拒绝集合是train与0，未显式排除验证物品、测试真值或之前已抽候选，因此候选可能重复，也可能再次抽到测试真值。超过10000用户时还随机抽10000用户评估。本页只核对这份脚本的行为；不能未经复现便把它当作论文主表每次运行的完整协议。
