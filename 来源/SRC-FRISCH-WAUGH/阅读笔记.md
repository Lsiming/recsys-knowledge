# Frisch 与 Waugh 为什么先去掉线性时间趋势

如果活动上线后市场总体也在增长，订单序列和营销投入可能同时随时间上升。可把时间趋势作为完整回归的一列，也可先对订单和每个解释变量各自回归到同一条时间趋势，再以这些残差做多元回归。在同一 OLS 样本上，两个过程对其余解释变量给出相同系数。只给订单去趋势而保留投入中的时间趋势，通常就得不到这个等式。Basu 对 1933 年论文的回溯指出，Frisch 与 Waugh 对中心化变量考虑一条线性趋势，用行列式和 Cramer 法则证明对应系数相等。 [Basu §4，式 (5)–(7)](https://arxiv.org/pdf/2307.00369v1#page=7)

用发券场景理解时，时间趋势可以去掉模型已表述的共同变化。活动当天若还调整了资格、入口和客群，是否识别券效应仍取决于这些变化能否与指派区分。Lovell 将线性时间趋势位置推广到一组控制变量。后续的 Robinson 变换再把有限维线性投影换成给定协变量的条件均值。 [本库推导与发券示例](../../知识库/问题/残差化怎样估计营销干预效应.md#从线性投影到条件均值) · [Lovell 条目](../SRC-LOVELL/阅读笔记.md)
