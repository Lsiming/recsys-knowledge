# 从推荐任务选择评估与教程

Recommenders 的 README 将工作拆成数据准备、模型、评估、调参与部署，并为算法提供 Quick start 或 Deep dive 的 Notebook 入口。它能把“想学习一种模型”连接到数据格式、训练输出和评估方式。

## 算法族与评估任务不能混为一谈

[Algorithms](https://github.com/recommenders-team/recommenders/blob/ba49f480a3a6604b09c8cde903958f9d9dca8a9d/README.md#L88)同时列出协同过滤、序列、内容方法和 VAE。生成模型早已出现在推荐算法目录中；“传统”与“生成式”不是天然互斥的两个技术集合。是否使用生成目标、是否用预训练语言模型、是否改变召排链路，需要分别判断。

评估说明将指标区分为评分误差、排序、二分类，以及多样性、新颖性、覆盖等。见 [Evaluate README](https://github.com/recommenders-team/recommenders/blob/ba49f480a3a6604b09c8cde903958f9d9dca8a9d/examples/03_evaluate/README.md#L10)。这支持 [评估与偏差](../../知识库/模块/评估、偏差与因果收益.md)按任务和候选集定义指标，而非把 AUC、Recall 和 RMSE 当作可互换的效果数字。

## 教程结果有自己的协议

[Algorithm Comparison](https://github.com/recommenders-team/recommenders/blob/ba49f480a3a6604b09c8cde903958f9d9dca8a9d/README.md#L136)给出了数据、切分、Top-K 和部分标签转换条件。目录中的数值只属于对应示例设置；这里不据此建立模型优劣榜，也不外推线上业务收益。
