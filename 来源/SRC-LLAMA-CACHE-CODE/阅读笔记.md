# Llama 2官方代码：旋转Key与逐层KV缓存

Meta Llama仓库固定commit `689c7f261b9c5514636ecc3c5fefefcbb3e6eed7` 的`llama/model.py`在`Attention.forward`先对投影后的Q/K调用`apply_rotary_emb`，然后把旋转后的K写进`cache_k`，V则直接写进`cache_v`。缓存形状按batch、sequence、KV heads和head dimension组织；`start_pos`对应新token在缓存中的绝对位置。代码直接支持“这份固定实现缓存旋转后的K”，不能单凭一个实现宣称所有模型或动态RoPE实现都必须同样处理。

这是固定版本代码的静态阅读，没有执行Torch/FairScale模型，也没有测量延迟或显存。可回查[固定源码](https://github.com/meta-llama/llama/blob/689c7f261b9c5514636ecc3c5fefefcbb3e6eed7/llama/model.py)中的`apply_rotary_emb`、`Attention.forward`与`Transformer.forward`。
