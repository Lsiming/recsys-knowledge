# 生成式推荐包含多条相交的技术路线

这份清单分别组织 LLM、Semantic ID 和 Diffusion 路线，又在内部划分对齐、训练推理、召排统一和混合检索。它适合帮助识别研究空间，不能把所属分组直接当成一篇论文的完整机制解释。

## 输出形式、骨干和任务角色是不同维度

[Semantic ID](https://github.com/hyp1231/awesome-generative-recommendation/blob/a35954110ab2240ae7ce98ab88647586d9ac0f2a/README.md#L289)下有量化、分层聚类、行为感知 Tokenization；[Architecture](https://github.com/hyp1231/awesome-generative-recommendation/blob/a35954110ab2240ae7ce98ab88647586d9ac0f2a/README.md#L383)下有生成与向量混合检索、统一召排；[Diffusion](https://github.com/hyp1231/awesome-generative-recommendation/blob/a35954110ab2240ae7ce98ab88647586d9ac0f2a/README.md#L427)又区分增强推荐、直接作为推荐模型以及个性化内容生成。

这支持 [生成式专题](../../知识库/总览/生成式推荐专题.md)同时关注“表示什么、预测什么、如何训练与解码、改变哪个系统阶段”。LLM、Semantic ID、扩散不是同一个层次的互斥标签。清单还收录内容生成和用户模拟，知识库会按实际推荐问题判断是否展开，避免自动扩大研究范围。

## 线索如何进入主干

P5、TIGER、LC-Rec、LIGER、HSTU、OneRec、S-DPO、Decoding Matters、AtSpeed 和 Diffusion Recommender Model 等条目进入 [候选阅读表](../../知识库/阅读/候选论文.md)。它们分别连接表示、检索、对齐、训练和解码问题。当前仅确认条目与链接，具体方法、适用条件和实验差异尚待逐篇阅读。
