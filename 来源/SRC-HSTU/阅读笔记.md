# 从 HSTU 官方仓库区分模型架构与实验协议

Meta Generative Recommenders 仓库提供 HSTU 相关工作的官方代码入口。README 同时讨论大规模序列建模、公开推荐实验和训练推理效率，说明其研究范围不能简化为“把物品编码成语义 ID 再生成”。

## 公开实验有明确的比较条件

[Public Experiments](https://github.com/meta-recsys/generative-recommenders/blob/f88532f2eea591361dd8796444971f66df82fe5d/README.md#L21)链接 MovieLens、Amazon 的数据处理与配置。[表后注释](https://github.com/meta-recsys/generative-recommenders/blob/f88532f2eea591361dd8796444971f66df82fe5d/README.md#L79)解释了 SASRec 的损失变体和不同模型使用的负样本条件。这些说明提示我们，骨干名称相同或同列一张表，并不自动表示训练与评估完全一致。

本轮没有采用 README 的效果和加速数字，也没有核对论文里的线上实验。后续 [兴趣序列](../../知识库/模块/用户兴趣与序列建模.md)与 [工程效率](../../知识库/模块/在线服务、更新与计算效率.md)的分析需要分别读取模型、损失、数据与 Kernel 实现。

## 模型层与系统层分别阅读

[Efficiency experiments](https://github.com/meta-recsys/generative-recommenders/blob/f88532f2eea591361dd8796444971f66df82fe5d/README.md#L103)给出 Triton/CUDA 等效率实验入口，[DLRM-v3](https://github.com/meta-recsys/generative-recommenders/blob/f88532f2eea591361dd8796444971f66df82fe5d/README.md#L240)提供训练推理命令。源码可取得不等于在本地硬件上可复现这些设置；公开数据实验也不能代替工业系统验证。

这份材料为 [生成式专题](../../知识库/总览/生成式推荐专题.md)提供规模化序列架构路线。具体是否采用物品生成、候选打分或两者组合，应随论文和配置判断。
