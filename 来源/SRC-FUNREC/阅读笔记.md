# 从级联链路理解推荐模块

推荐算法可以沿“找到候选、预测偏好、组织列表”理解。fun-rec 的章节目录先介绍协同过滤、向量和序列召回，再展开特征交叉、兴趣序列、多目标、多场景，最后讨论重排。这条路径把算法放回系统职责中，适合建立第一层学习地图。

## 目录提供的两种观察尺度

[章节目录第 19–35 行](https://github.com/datawhalechina/fun-rec/blob/5f7bd84d4403b5f92b6bedbd31e3984ef00a4572/README.md#L19)按级联阶段和建模能力组织内容。召回、精排、重排属于链路阶段；序列、多目标、多场景则可以被多个阶段使用，不能简单排列成互不重叠的流水线。

[第 37–60 行](https://github.com/datawhalechina/fun-rec/blob/5f7bd84d4403b5f92b6bedbd31e3984ef00a4572/README.md#L37)另列生成式基础、Tokenizer、HSTU、端到端生成、推理和扩散模型。这个目录说明生成式路线涉及表示、架构、训练和系统组合多个层次；把所有内容压成一个单独的“生成式模型模块”，会失去与已有问题的对应关系。

据此，[推荐系统总图](../../知识库/总览/推荐系统总图.md)采用统一模块主干，[生成式专题](../../知识库/总览/生成式推荐专题.md)沿这些模块组织阅读路线。这是针对本知识库学习目标的组织选择，不是原教程唯一的分类方法。

## 教程适合做学习顺序，效果仍需回到论文

README 明确项目持续开发。目录与内容简介可以支持主题覆盖和阅读顺序，不能证明章节中的每个实现已经通过生产验证，也不能据此确认各模型的效果。后续精读应定位具体论文、实验协议和代码版本。
