# Using the Output Embedding to Improve Language Models

Press与Wolf在§1解释输入嵌入矩阵和输出分类嵌入矩阵的不同角色，并研究令两者共享同一参数的weight tying；§3推导共享矩阵每行的梯度会汇总输入与输出两种用途，并在论文所测语言模型和神经机器翻译设置中报告效果。该实证不是“所有任务都一定提高”的普遍保证。Transformer三方共享方式仍以Vaswani等人的§3.4为直接依据。

证据范围：arXiv 1608.05859v3，定向阅读§1、§3；未复现实验、未全文翻译。
