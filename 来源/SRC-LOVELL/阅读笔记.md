# Lovell 怎样把季节调整写成同一套回归投影

月度销售分析常需同时处理年度趋势、月份季节性和促销。Frisch–Waugh 考察一条线性时间趋势。Lovell 的推广允许在季节调整等应用里，把全部解释变量分成任意大小的两块。设保留的是活动投入 $D$，待调整的是控制矩阵 $Z$。先用相同投影除去 $Y$ 和 $D$ 中落在 $Z$ 列空间的分量，再对残差回归，所求活动投入系数与完整模型相同。现代教材的投影矩阵写法可将这个过程表示为 $\hat\theta=(D^\top M_ZD)^{-1}D^\top M_ZY$。 [Basu §5.1，式 (8)–(11)](https://arxiv.org/pdf/2307.00369v1#page=8)

Basu 同时回溯了完整回归与偏回归拟合残差相同的结论。两者使用同一投影、同一样本，且目标列在去除控制后仍有可识别的变化。估算同方差标准误时，误差方差应按完整回归的自由度计算；异方差或聚类方差还要核对具体校正公式。一旦把销量、处理各自改用不同样本或不同月份基准去残差，就失去了这个投影恒等式。 [Basu §5–6](https://arxiv.org/pdf/2307.00369v1#page=8) · [本库推导](../../知识库/问题/残差化怎样估计营销干预效应.md#从线性投影到条件均值)
