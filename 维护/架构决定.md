# 架构决定

2026-10-25，KB-001；本次用户授权按合适方式直接重构，既有方案作为参考。来源为 [三份参考笔记](../来源/来源目录.md) 与 [原设计研究](../文档/治理/20261025_推荐系统知识库设计/01_参考资料研究.md)。

| 决定 | 理由与代价 |
|---|---|
| 从知识地图启动，按任务读取上下文 | 日常问题不必先加载多份执行状态文件；恢复任务仍查唯一队列与交接 |
| 来源、知识、操作元数据、临时任务分开 | 来源摘要与跨来源理解不重复；根 MEMORY/SESSION 不再承担领域知识存储 |
| Markdown + 相对链接 + 稳定 ID | Codex/Claude Code、普通编辑器、Obsidian 均可读；暂不依赖插件或服务器 |
| 来源原字节按哈希本地冻结，轻量版本账本进 Git | 避免原件和大型上游源码膨胀仓库；原件需单独备份，哈希本身不能恢复 |
| Agent 做理解/合并，标准库工具做登记/索引/检查 | 复用当前代码智能体，无新增模型 API 或桌面应用依赖；语义质量仍需证据自查 |
| 缓存检查来源版本、阅读笔记、协议和输出绑定 | 字节没变但阅读或规则变化仍可重新处理；保留旧版本、显式暴露待办 |
| 引用绑定版本，来源升级提示直接影响与关联候选 | 避免更新摘要后旧知识静默失效；关联提示不是逐条论证自动撤销 |
| 索引自动生成，知识综合由 Agent 维护 | 程序列表不冒充新的全局综述；新增页无需手填多处目录 |
| 保留旧 docs 路径和设计原文 | 维持历史链接、已有未提交改动与追溯；文档/README 明确当前入口和旧提案状态 |
| 保留 TODO、任务交接和简短根状态 | 现有任务注册习惯继续有效，但不强制每个问题建立交接；不重复维护第二套任务库 |

暂不引入向量库、图数据库、定时任务、Tauri 桌面端或全自动批量 LLM 摄入。真实使用中出现词面检索漏召回、规模/维护成本问题后再按证据扩展，不照搬上游全部功能。没有运行 nashsu 应用或复测其效果数字。

历史提案中的“尚未实施”描述仅适用于提案提交时；现行实现以本页、SCHEMA、工具与 [KB-001 交接](../文档/会话/KB-001.md) 为准。重构前上下文按原字节留存于 [历史归档](../文档/历史归档/目录.md)。

## 2026-10-25 · KB-002：论文学习与技术正文

用户明确希望给论文后直接完成翻译、精读、知识提炼与跨方法比较，并按模块学习问题与解法；具体页面应偏技术文章、适合人读。这些是本项目使用选择，不冒称三份外部参考的原文要求。

| 决定 | 理由与代价 |
|---|---|
| problem 页用 module + solutions 关联问题、解法和论文 | 一个问题可有多解，一种解法可有多篇论文；索引自动汇总，避免手工重复维护关系 |
| 一篇主要精读笔记 + 少量问题页 | 单篇解释和跨篇综合各有归属；仅真正可复用时独立建概念/方法页 |
| 正文写技术文章，状态留元数据 | 读者顺着问题、机制和证据学习；文章不承担 Agent 提示、收据或任务日志 |
| 常规单篇不建额外任务/交接 | 给论文即可开始；跨会话中断、并发、系统改造、实验仍登记以便恢复 |
| 翻译复用 arxiv-translator，无源码则尽可行保存中文 Markdown | 不保证每个来源均能编译 PDF；翻译遇阻继续原文精读，如实记录未完成项 |
| 显式处理语义版本替代全规则/工具代码哈希 | 排版与导航不触发全库重复摄入；代价是维护者须判断实质规则变更是否需要升版 |

知识页、来源目录和正文中的论文链接支持双向查找；检索仍是词面匹配。实际推荐论文的翻译与比较质量须在资料到来后验证，测试用临时样例不进入正式知识库。交付与检查见 [KB-002](../文档/会话/KB-002.md)。

## 2026-10-25 · KB-003：统一推荐主干与候选阅读

用户讨论后授权先建设领域框架、梳理论文，再逐篇指定翻译和精读。此次按 [九份 GitHub 资源](../知识库/总览/学习资源导读.md)的指定 README 范围组织问题，不宣称已完成系统文献综述。

| 决定 | 理由与代价 |
|---|---|
| 传统与生成式推荐共用模块/问题，生成式保留跨模块专题 | 同一问题能比较不同解法；统一召排等联合改造也能表达，避免两套重复正文 |
| 按链路阶段与共用能力建立 14 个模块导读 | 既看候选如何逐级决策，也看表征、训练、评估、计算和长期收益；模块不被误读为互斥流水线 |
| 模块主导读用 map + module，由索引自动发现 | 尚无精读论文时也能开始学习；每模块唯一入口，正式 problem/solutions 的论文证据要求保持不变 |
| 38 篇候选集中维护身份、发现依据和问题反链 | 未读不建虚假论文笔记或比较结论；后续精读后再链接真实来源和问题页 |
| 九份 GitHub 资料固定 commit 与 README 哈希 | 分类和条目可以回查；只保存实际阅读的原件范围，不克隆项目或运行基准 |
| 营销补贴保留为相关应用入口 | 从因果增量、预算和策略接入共同问题，专门文献后续补齐，不凭推荐离线数字外推补贴收益 |

此次补充页面组织和导航，不改变旧来源提取/证据/合并标准，处理语义版本保持 1。实施与真实验证见 [KB-003](../文档/会话/KB-003.md)。
