# 按任务选择上下文

先读 [知识地图](../知识库/知识地图.md) 再搜索，以下只是最小阅读路由，不复制知识正文。此索引变化不意味着已经读取所有链接内容。

| 当前任务 | 核心入口 | 何时展开 |
|---|---|---|
| 用户给一篇论文 | [论文标准流程](工作流.md#论文知识沉淀标准流程)、[知识契约](../SCHEMA.md)、检索已有来源/问题 | 沿用 ESMM 链路：先取得原件/LaTeX，再翻译核查、技术精读、合并问题方案并验证检索。常规单篇无需加载根状态与历史交接 |
| 学习某个模块 | [系统总图](../知识库/总览/推荐系统总图.md)、[知识地图](../知识库/知识地图.md) 的模块导读 | 先看职责、问题与解法族；已有问题页再看论文机制/异同。不先读系统设计与维护史 |
| 学习搜索或定位生成式搜索论文 | [搜索系统总图](../知识库/总览/搜索系统总图.md)、对应查询理解/改写规划/联想/相关性模块 | 先区分输出是结构、检索请求、建议查询还是相关性判断；当前9篇只读摘要，精读再补正式问题与解法。召排、训练、服务和评估复用已有模块 |
| 理解生成式推荐与已有方法的关系 | [生成式专题](../知识库/总览/生成式推荐专题.md) | 沿表示、检索、架构、训练、解码和服务进入同一模块，不另建重复正文 |
| 按经典论文建立基础 | [模块经典与第一轮主线](../知识库/阅读/经典论文路线.md) | 每模块先看经典基础、代表工作与新路线起点；仍逐篇指定翻译/精读 |
| 找下一篇论文或 GitHub 学习材料 | [候选论文](../知识库/阅读/候选论文.md)、[资源导读](../知识库/总览/学习资源导读.md) | 候选反链模块问题；需要精读再固定原文。清单和 README 不充当论文实验结论 |
| 理解持续知识库 | [持久知识层](../知识库/概念/持久知识层.md)、[维护闭环](../知识库/综合/知识维护闭环.md) | 需要工程取舍再读 [增量与失效](../知识库/概念/增量摄入与失效传播.md) |
| 摄入论文/解读/代码 | [知识契约](../SCHEMA.md)、[维护工作流](工作流.md)、[来源目录](../来源/来源目录.md) | 运行 plan，再读受影响知识页；科研资料另读 [研究要求](../文档/规范/研究工作流.md) |
| 回答推荐/补贴/生成式推荐问题 | 搜索知识库的模块、问题、方案或论文名 | 缺证时定向补查；用户已给论文则直接处理，不先要求另行选题；不把系统参考冒充算法证据 |
| 复核证据、比较结论 | [证据与适用范围](../知识库/概念/证据与适用范围.md)、[审核台](审核台.md) | 展开具体来源笔记与固定原文 |
| 获取/备份原文或中文PDF | [PDF私有维护流程](../文档/工具/中文PDF发布.md)、[PDF盘点](../译文/PDF目录.md) | 原文与译文在独立私有库，需有权账号；原件恢复核对来源卡原哈希。公开PR/CI不需要附件或私有权限 |
| 维护脚本或迁移 | [工具说明](../scripts/README.md)、[架构决定](架构决定.md)、SCHEMA | 模块地图/候选导航见 [KB-003](../文档/会话/KB-003.md)，论文流程见 [KB-002](../文档/会话/KB-002.md)；首轮迁移证据见 [KB-001](../文档/会话/KB-001.md) |
| 恢复任务/了解项目状态 | [任务队列](../TODO.md)、[总交接](../SESSION.md)、任务交接 | [当前事实](../PROJECT_MEMORY.md) 只供当前事实速查；旧记录仅查证 |
| 并发修改/整合 | [协作规范](../文档/规范/上下文与多会话协作.md) | 明确文件归属、工作树和串行提交者；默认不委派子 Agent |

检索支持模块名、问题、解法名、论文题名/来源 ID；问题页的方案与论文引用也参与匹配。需要精确原文片段时用 `rg -n '关键词|别名' 知识库 来源`。脚本仍是词面检索，不宣称语义召回率。
