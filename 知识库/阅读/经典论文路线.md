# 从经典论文开始：模块起点与第一轮主线

首批P01–P38均已完成精读、问题比较与中文PDF交付；从[候选表](候选论文.md)反查每篇阅读笔记与译文，翻译范围及原文保留部分见笔记文末。本轮补齐25篇原缺PDF，并恢复[YouTube DNN](../../来源/SRC-YOUTUBE-DNN/阅读笔记.md)、[DIN](../../来源/SRC-DIN/阅读笔记.md)、[MMoE](../../来源/SRC-MMOE/阅读笔记.md)、[Herlocker评估综述](../../来源/SRC-HERLOCKER-EVAL/阅读笔记.md)与[On Sampled Metrics](../../来源/SRC-SAMPLED-METRICS/阅读笔记.md)，详见[PAPER-001](../../文档/会话/PAPER-001.md)。

先从少量基础论文建立概念和比较坐标，再进入新模型。这里的“经典基础”是本知识库的学习编排：侧重奠基性、模块代表性和后续依赖，不按引用量排名，也不表示已完成论文证据核验。各篇实际进度见[候选表](候选论文.md)，已读论文可直接进入精读与问题页。

- **经典基础**：优先建立问题定义、常用机制和基本评估视角。
- **代表/进阶**：用于看一个模块怎样从基础问题向具体结构或系统取舍发展。
- **新路线起点**：用于较新的语义 ID、生成检索和偏好对齐；不直接等同于历经长期验证的经典。

## Transformer基础与推荐衔接

读完基础论文后，可沿[问题驱动路线](Transformer问题驱动学习路线.md)反查QKV形状、mask、归一化、位置与推理；[八篇构件论文](Transformer问题驱动学习路线.md#从四个问题回到八篇构件论文)按词表、归一化、位置和注意力计算连接到对应精读。

序列推荐描述的是输入与预测问题，Transformer描述的是网络结构，生成式推荐还涉及输出对象与训练目标，三者不能画等号。[SASRec](../../来源/SRC-SASREC/阅读笔记.md)用因果自注意力编码历史并对物品打分；[TIGER](../../来源/SRC-TIGER/阅读笔记.md)用编码器—解码器Transformer生成物品语义码；[P5](../../来源/SRC-P5/阅读笔记.md)以预训练T5统一个性化文本任务；[LC-Rec](../../来源/SRC-LCREC/阅读笔记.md)以LLaMA学习索引与语言、行为的对齐。这些工作共享或改造Transformer结构，但预测对象和训练目标各有不同。

[DIEN](../../来源/SRC-DIEN/阅读笔记.md)的兴趣演化依靠GRU及注意力门控，[Seq2Slate](../../来源/SRC-SEQ2SLATE/阅读笔记.md)用LSTM指针逐项选择候选，[DiffRec](../../来源/SRC-DIFFREC/阅读笔记.md)用MLP去噪网络恢复交互向量，说明序列和生成任务也可以采用其他结构。[HSTU](../../来源/SRC-HSTU-PAPER/阅读笔记.md)则改写了注意力、门控与算子组织，不宜当作原版Transformer的直接复制。这些关联依据库内既有精读，不代表本轮重新核对了各篇全文。

起点选[《Attention Is All You Need》](候选论文.md#p54)，先理解Q/K/V如何根据当前位置检索其他位置的信息，再看多头如何学习不同关系、位置编码如何提供顺序、前馈网络如何变换各位置特征。最后分清三种注意力：编码器内的双向自注意力、解码器内遮住未来的自注意力，以及解码器读取编码器输出的交叉注意力。五篇现均有正文中文PDF、可编辑工程与独立精读；[Transformer精读](../../来源/SRC-TRANSFORMER/阅读笔记.md)和[上下文机制比较](../问题/序列怎样用自注意力建立上下文.md)适合作为起点，具体交付范围见各篇笔记文末。原文优先读§3，再读§4理解序列计算的取舍；§5–6的训练与实验设置留到结构清楚后阅读。这是建议的学习顺序，新增基础论文的核对范围见[候选表](候选论文.md#transformer基础与推荐衔接)。

### 以Transformer与生成式推荐为主线

已经读过Transformer、SASRec和GPT初代时，建议先用 **BERT → BERT4Rec** 补齐早期自注意力方法的另一条分支，再进入 **T5 → TIGER**。顺序按理解依赖编排，不是严格的发表年表：GPT与BERT提供两种预训练视角，SASRec与BERT4Rec提供推荐任务中的对应比较；TIGER的物品编码与生成检索另有设计，不是逐篇继承同一模型的直线。

| 顺序 | 带着什么问题读 | 阅读重点 |
|---|---|---|
| 1. [BERT](../../来源/SRC-BERT/阅读笔记.md) | 对照GPT，为什么双向读取需要改变预训练任务？ | 掩码Token与注意力遮罩、MLM监督位置、预训练与微调；重点看§3与§5.1 |
| 2. [BERT4Rec](../../来源/SRC-BERT4REC/阅读笔记.md) | 对照SASRec，双向恢复怎样服务下一物品预测？ | 历史中间遮罩与末尾MASK；在推荐数据上从零训练，不加载语言BERT权重 |
| 3. [T5](../../来源/SRC-T5/阅读笔记.md) | 怎样把双向条件理解与因果生成结合？ | 编码器、解码器、交叉注意力与片段去噪；先读§2.1、§2.4、§3.1.4与§3.2 |
| 4. [TIGER](../../来源/SRC-TIGER/阅读笔记.md) | 怎样从物品打分转到生成物品地址？ | 内容向量、RQ-VAE残差量化、语义ID与消歧、历史到目标码的训练及目录映射 |
| 5. [LETTER](../../来源/SRC-LETTER/阅读笔记.md) / [LC-Rec](../../来源/SRC-LCREC/阅读笔记.md) | 内容接近为什么不必然意味着用户行为接近？ | 前者在Tokenizer侧加入协同约束，后者通过调优任务对齐语言、索引与行为；是不同改进位置 |
| 6. [OneRec](../../来源/SRC-ONEREC/阅读笔记.md) | 从下一物品到会话码序列，目标与系统如何变化？ | 列表依赖、奖励模型、偏好对齐与服务成本；到此处再补DPO与MoE基础 |

BERT与BERT4Rec适合用于理解早期方法迭代，短支线读完后继续生成式推荐。双向恢复不是后来所有生成方法的统一起点，BERT4Rec也不是TIGER式的多Token物品地址生成。机制比较见[因果预测与双向恢复](../问题/从历史顺序预测下一物品.md)和[预训练迁移](../问题/预训练怎样迁移到不同任务.md)；不能据学习顺序推断后一篇在所有条件下都优于前一篇。

[P5](../../来源/SRC-P5/阅读笔记.md)可在T5后选读，帮助理解推荐任务的文本化接口，不是TIGER的硬前置。HSTU、OneRec-V2、推理增强与扩散留到主链清楚后按问题展开，不要求先读完整的语言模型或传统推荐发展史。

## 第一轮主线

先读 [YouTube DNN](候选论文.md#p02) 看全链路，再读 [BPR](候选论文.md#p01) 理解样本与排序目标。精排从 [DeepFM 精读](../../来源/SRC-DEEPFM/阅读笔记.md)与[交互问题](../问题/稀疏特征的低高阶交互学习.md)开始，兴趣建模选 [DIN](候选论文.md#p10) 和 [SASRec](候选论文.md#p12)；多任务接 [ESMM](候选论文.md#p14)、[MMoE](候选论文.md#p15)，列表接 [DPP](候选论文.md#p20)。最后进入 [TIGER精读](../../来源/SRC-TIGER/阅读笔记.md)与[语义码生成检索比较](../问题/用语义短码直接检索物品.md)，把新生成方式放回已有问题比较。

[协同过滤评估综述](候选论文.md#p37)与 [On Sampled Metrics](候选论文.md#p38) 作为伴读：每读一篇都问“任务、切分、候选集、指标与计算预算是什么”。若 Wide & Deep、图协同或延迟反馈出现理解缺口，再按模块表插入相应论文，不要求先读完整张清单。

每次只指定一篇题名、链接或候选编号，即走翻译 → 精读 → 知识提炼 → 问题/方案沉淀。具体任务与实验条件到精读时核对，未读论文不提前给出方法优劣结论。

完整身份、原文入口和发现依据见 [候选论文表](候选论文.md)，模块关系见 [推荐系统总图](../总览/推荐系统总图.md)，生成式跨模块路线见 [专题](../总览/生成式推荐专题.md)。
