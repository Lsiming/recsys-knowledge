先从少量基础论文建立概念和比较坐标，再进入新模型。这里的“经典基础”是本知识库的学习编排：侧重奠基性、模块代表性和后续依赖，不按引用量排名，也不表示已完成论文证据核验。除上文链接的已读论文外，各论文仍是待翻译、待精读候选。

- **经典基础**：优先建立问题定义、常用机制和基本评估视角。
- **代表/进阶**：用于看一个模块怎样从基础问题向具体结构或系统取舍发展。
- **新路线起点**：用于较新的语义 ID、生成检索和偏好对齐；不直接等同于历经长期验证的经典。

## Transformer基础与推荐衔接

序列推荐描述的是输入与预测问题，Transformer描述的是网络结构，生成式推荐还涉及输出对象与训练目标，三者不能画等号。[SASRec](../../来源/SRC-SASREC/阅读笔记.md)用因果自注意力编码历史并对物品打分；[TIGER](../../来源/SRC-TIGER/阅读笔记.md)用编码器—解码器Transformer生成物品语义码；[P5](../../来源/SRC-P5/阅读笔记.md)以预训练T5统一个性化文本任务；[LC-Rec](../../来源/SRC-LCREC/阅读笔记.md)以LLaMA学习索引与语言、行为的对齐。这些工作共享或改造Transformer结构，但预测对象和训练目标各有不同。

[DIEN](../../来源/SRC-DIEN/阅读笔记.md)的兴趣演化依靠GRU及注意力门控，[Seq2Slate](../../来源/SRC-SEQ2SLATE/阅读笔记.md)用LSTM指针逐项选择候选，[DiffRec](../../来源/SRC-DIFFREC/阅读笔记.md)用MLP去噪网络恢复交互向量，说明序列和生成任务也可以采用其他结构。[HSTU](../../来源/SRC-HSTU-PAPER/阅读笔记.md)则改写了注意力、门控与算子组织，不宜当作原版Transformer的直接复制。这些关联依据库内既有精读，不代表本轮重新核对了各篇全文。

起点选[《Attention Is All You Need》](候选论文.md#p54)，先理解Q/K/V如何根据当前位置检索其他位置的信息，再看多头如何学习不同关系、位置编码如何提供顺序、前馈网络如何变换各位置特征。最后分清三种注意力：编码器内的双向自注意力、解码器内遮住未来的自注意力，以及解码器读取编码器输出的交叉注意力。原文优先读§3，再读§4理解序列计算的取舍；§5–6的训练与实验设置留到结构清楚后阅读。这是建议的学习顺序，新增基础论文的核对范围见[候选表](候选论文.md#transformer基础与推荐衔接)。

| 学习问题 | 推荐顺序 | 回到当前知识库 |
|---|---|---|
| 自注意力怎样建模用户历史？ | [Transformer](候选论文.md#p54) → [SASRec](候选论文.md#p12) | [从历史顺序预测下一物品](../问题/从历史顺序预测下一物品.md)：物品与位置表示、因果遮罩、候选打分 |
| 只读前缀与双向恢复有何区别？ | [BERT](候选论文.md#p56) → [BERT4Rec](候选论文.md#p57)，对照SASRec | [用户兴趣与序列建模](../模块/用户兴趣与序列建模.md#q-next)：区分训练时可见上下文与真实预测时已有历史；不预设双向模型一定更好 |
| 自回归生成怎样训练？ | [GPT初代](候选论文.md#p55)，再回看[LC-Rec](../../来源/SRC-LCREC/阅读笔记.md) | [训练与对齐](../模块/训练目标与偏好对齐.md)：下一Token目标与推荐监督；GPT用于建立概念，不替代LLaMA细节核对 |
| 给定历史怎样生成文本或物品码？ | [T5](候选论文.md#p58) → [P5](../../来源/SRC-P5/阅读笔记.md) → [TIGER](../../来源/SRC-TIGER/阅读笔记.md) | [统一个性化任务](../问题/如何用语言接口统一个性化推荐任务.md)、[语义码生成检索](../问题/用语义短码直接检索物品.md)：比较条件输入、输出标识与解码过程；TIGER与T5/P5之间不是简单的模型继承关系 |

如果先抓与你当前问题最直接的主线，建议 **Transformer → SASRec → T5 → TIGER**，然后补BERT/BERT4Rec和GPT。无需把所有语言模型发展史读完后再学推荐。

## 第一轮主线

先读 [YouTube DNN](候选论文.md#p02) 看全链路，再读 [BPR](候选论文.md#p01) 理解样本与排序目标。精排从 [DeepFM 精读](../../来源/SRC-DEEPFM/阅读笔记.md)与[交互问题](../问题/稀疏特征的低高阶交互学习.md)开始，兴趣建模选 [DIN](候选论文.md#p10) 和 [SASRec](候选论文.md#p12)；多任务接 [ESMM](候选论文.md#p14)、[MMoE](候选论文.md#p15)，列表接 [DPP](候选论文.md#p20)。最后进入 [TIGER精读](../../来源/SRC-TIGER/阅读笔记.md)与[语义码生成检索比较](../问题/用语义短码直接检索物品.md)，把新生成方式放回已有问题比较。

[协同过滤评估综述](候选论文.md#p37)与 [On Sampled Metrics](候选论文.md#p38) 作为伴读：每读一篇都问“任务、切分、候选集、指标与计算预算是什么”。若 Wide & Deep、图协同或延迟反馈出现理解缺口，再按模块表插入相应论文，不要求先读完整张清单。

每次只指定一篇题名、链接或候选编号，即走翻译 → 精读 → 知识提炼 → 问题/方案沉淀。具体任务与实验条件到精读时核对，未读论文不提前给出方法优劣结论。

完整身份、原文入口和发现依据见 [候选论文表](候选论文.md)，模块关系见 [推荐系统总图](../总览/推荐系统总图.md)，生成式跨模块路线见 [专题](../总览/生成式推荐专题.md)。
