# 候选论文：从问题反查阅读入口

首批 38 篇保留 P01–P38 稳定编号，已全部尝试：38 篇均已有译文、精读、问题比较与逐页检查的中文 PDF（具体翻译范围见笔记）。逐篇交付与缺项见 [PAPER-001](../../文档/会话/PAPER-001.md)。2026-10-26补入15篇生成式搜推候选P39–P53，其中OneSug及本批七篇推荐相关论文已完成对应范围全文学习，其余8篇搜索仍按摘要边界保留，详见[新增阅读线索](#用户补充的生成式搜推论文)。未读论文的问题是需要核实的方向，不是已确认的方法结论；导航排列不表示效果排名或既定学习顺序。当前没有论文的本仓库模型复现结果。

论文名集中保存在本页，模块页用简称链接到这里；每条候选反链具体模块问题。GitHub 条目绑定本次读取的 commit，原文入口多数未固定论文版本，选中精读时再固定版本与原件。清单 PDF 镜像不视为作者官网，仓库实现也不统一称为原作者官方代码。BPR、LightGCN、SASRec 曾额外核对 arXiv 题名与标识；三篇现均已精读并登记固定版本。年份、作者与发表场所在后续正式登记时完整核对，避免继承清单错误。

[精读流程覆盖核查](../../维护/论文精读流程覆盖核查.md)列出已验收、待补原图、待按新版重读及待全文精读的论文。 [论文分批精读路线](论文分批精读路线.md)按主题列出每批论文、处理方式和知识回写入口。

## 怎样选择第一篇

建立推荐链路直觉可先选 YouTube DNN；理解序列预测可先选 SASRec，再沿候选条件兴趣与长序列展开；理解语义 ID 生成检索可先选 TIGER，再比较 LC-Rec、LIGER 与解码问题。这是学习路线建议，不是用户必须遵守的前置顺序。

后续直接指定题名、链接或编号即可启动标准论文流程。完成精读后，正文仍以该论文的来源 notes 为主，复用结论并入对应问题页；本页改为链接真实笔记，保留候选到知识的来路，不复制第二份精读。

检索范围与资源用途见 [资源导读](../总览/学习资源导读.md)，统一模块入口见 [推荐系统总图](../总览/推荐系统总图.md)，生成式路线见 [专题导读](../总览/生成式推荐专题.md)。首批资源检索截至 2026-10-25；用户补充候选登记于 2026-10-26，同日后续定向读取其中9篇搜索论文摘要；未声称覆盖这些日期前全部主流或最新工作。
