# 营销补贴待读论文

从[营销补贴总图](../总览/营销补贴总图.md)进入业务问题，从[因果推断与 Uplift 预估](../模块/因果推断与Uplift预估.md)查已有的增量估计方法。这份清单从贝子涵的 32 篇知乎文章筛出 74 条候选文献。表中论文编号仅在本页使用，文号可跳转到知乎出处。 [知乎文章列表](https://www.zhihu.com/people/huan-you-4-9/posts)

清单按问题和交付范围组织。60 条按[论文标准流程](../../维护/工作流.md#论文知识沉淀标准流程)安排翻译、精读与知识沉淀，14 条只做解读与知识沉淀。开始阅读时用题名或 DOI／arXiv ID 查询[来源目录](../../来源/来源目录.md)，沿用已有来源和笔记。其他方向的书目见[候选论文](候选论文.md)。

时序因果条目关注干预后的结果与效应。HMUM 对应短视频场景中的多干预 Uplift 和目标权衡。LTV 条目关注客户终身价值建模及衡量。
