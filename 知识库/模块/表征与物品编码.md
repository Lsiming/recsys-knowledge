# 表征与物品编码

推荐中的表示承担两项不同职责：表达物品之间的关系，以及让系统准确指向一个可返回的物品。连续向量适合计算相似度；离散 ID 便于索引或生成，但 ID 的语义、唯一性和更新方式都需要另行设计。

协同表示从用户—物品交互学习“哪些物品被相似的人消费”；内容表示从文本、图像等描述学习相似性。两者提供的信息并不相同。冷启动时内容可在交互不足前提供线索，是否转化为推荐收益还取决于对齐、分布和候选资格。

先读 [BPR](../阅读/候选论文.md#p01) 与 [LightGCN精读](../../来源/SRC-LIGHTGCN/阅读笔记.md)，分别作为协同表征的经典基础和图协同过滤代表；理解这些输入信号后，再读 [TIGER精读](../../来源/SRC-TIGER/阅读笔记.md)与[语义短码检索](../问题/用语义短码直接检索物品.md)，进入语义 ID 的新路线起点。完整的起点选择见 [经典阅读路线](../阅读/经典论文路线.md)。

[Item ID 清单](../../来源/SRC-ITEMID-SURVEY/阅读笔记.md)把构建标识与对齐分开。[GRID README](../../来源/SRC-GRID/阅读笔记.md)明确展示“文本向量 → 语义 ID → 推荐生成”，并说明额外层级可用于区分重复语义 ID。这表明量化质量与物品唯一可寻址性需要分别检查，不能只看向量重建误差。

[TIGER](../../来源/SRC-TIGER/阅读笔记.md#共享语义与唯一寻址是两件事)已经给出论文依据：三级内容残差码后加一位消歧码，语义共享与唯一寻址分别处理；推荐训练在ID冻结后进行，并非内容与协同端到端联合量化。

[交互图协同表示](../问题/利用交互图传播协同表示.md)比较BPR-MF与LightGCN：同样以正负分差监督，后者在预测结构中显式归一化聚合邻居、组合各层表示。它只有初始ID参数，但传播有额外边遍历成本；不能将纯ID实验中去掉非线性的收益推广到全部富属性图。

一个离散码可写为 z(i)=(c₁,…,cₗ)。共享前缀只说明编码设计让物品共享了部分路径，并不自动保证推荐偏好相似。编码如何用于找候选见 [召回](召回与检索.md)，如何约束合法路径见 [生成与解码](生成机制与约束解码.md)，如何注入行为监督见 [训练与对齐](训练目标与偏好对齐.md)。

[P5的ID子词与TIGER语义码比较](../问题/如何用语言接口统一个性化推荐任务.md#id子词共享与语义码共享解决不同问题)区分两类共享：P5整词Embedding帮助识别输入字段，ID数字片段不是内容量化码；TIGER另训练RQ-VAE建立共享语义层级与消歧映射。

[LC-Rec与TIGER的消歧比较](../问题/用语义短码直接检索物品.md#末层平衡分配与追加身份码有不同的保证条件)区分末层平衡传输和额外身份码：平衡软质量不自动证明硬码唯一，固定末码容量仍约束同前缀可寻址物品数。

[GRID组件比较](../问题/用语义短码直接检索物品.md#简单量化与复杂生成之间怎样分配预算)说明简单量化、码长、碰撞消歧与合法码搜索应分开评价；平均命中接近不能替代每件物品唯一寻址或合法性保证。实验收益依赖当前数据、样本增强及默认配置，未验证量化线上加速。
