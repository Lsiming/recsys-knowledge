# 多任务学习与多目标决策

推荐常同时关心点击、转化、停留和留存。多任务学习研究这些标签怎样共享信息；多目标决策研究最终列表如何权衡多个结果。两者有关，但训练出多个预测头并不会自动决定业务取舍。

若点击 C 与转化 V 存在“转化必先点击”的事件关系，可写 P(C∩V|x)=P(C|x)P(V|C,x)。这个概率恒等式要求事件与窗口一致；它本身不保证有限样本中的估计无偏，也不能修复所有曝光选择问题。

## 从经典论文开始

经典基础先选 [ESMM](../阅读/候选论文.md#p14) 与 [MMoE](../阅读/候选论文.md#p15)，分别带着“条件事件/训练空间”和“任务共享”问题阅读，再读 [PLE](../阅读/候选论文.md#p16)（进阶代表）。多任务结构与最终多目标决策始终分开讨论。完整的起点选择见 [经典阅读路线](../阅读/经典论文路线.md)。

多任务入口见 [FuxiCTR](../../来源/SRC-FUXICTR/阅读笔记.md)与 [工业清单](../../来源/SRC-INDUSTRIAL-REC/阅读笔记.md)。[点击后转化率估计](../问题/点击后转化率估计.md) 已依据 ESMM 原文比较其中的 BASE、DIVISION、ESMM-NS 与 ESMM；[多任务共享如何避免负迁移](../问题/多任务共享如何避免负迁移.md) 已依据 PLE 原文比较 CGC、PLE 与本篇 MMOE 对照：限制可见专家集合、低层经共享支路交换信息、高层逐渐形成任务表示。MMoE已补读原文，PLE内部对照与MMoE自身实验分别定位。PLE 的样本掩码处理任务标签有效域，ESMM 的乘法约束利用全曝光联合事件，二者解决不同层面的困难；训练损失权重也不等于最后排序权重。

生成模型也可能联合学习多个行为或任务，并面对偏好冲突。多个场景是否共享是 [多场景](多场景、迁移与冷启动.md)问题；单次效用与长期目标的关系见 [探索与长期收益](探索、长期收益与策略学习.md)。

[MMoE精读](../../来源/SRC-MMOE/阅读笔记.md)补齐独立任务门的原文依据：各任务对同一专家池密集Softmax加权，按样本改变共享组合。原版没有Top-K稀疏执行，工业效率证据来自仅替换共享底层顶层的特定实现。
