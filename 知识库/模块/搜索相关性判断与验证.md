# 搜索相关性判断与验证

搜索结果需要回答“它是否满足这次查询”。这与“用户有多大概率点击或购买”相关，但不是相同标签：一个热门且高点击的结果仍可能违背查询限制。这里的输入是查询、候选及可用证据，输出是相关性类别、分数或验证决定；如何把它用于过滤、排序或其他环节，需要按实际系统区分。

[TaoSR1](../../来源/SRC-TAOSR1/阅读笔记.md)采用四级标签训练，用首个位置的标签概率为搜索商品分档。[LEAPS](../../来源/SRC-LEAPS/阅读笔记.md)在扩展后的下游核对完整原查询，并用冻结验证器为扩展器提供训练奖励。两者在标签、证据和执行用途上的边界见各节。

## 相关性证据、分档与部署

<a id="q-reasoning"></a>**相关性推理怎样处理理由看似合理、标签却错误的情况？** [TaoSR1](../../来源/SRC-TAOSR1/阅读笔记.md#训练时让标签和解释共同监督)向教师提供人工标签及检索来的原子业务规则。学生先生成标签，再生成理由。输出顺序使当前标签不依赖先生成的显式理由。DPO 用正确轨迹和错误轨迹做偏好对，全错难例的正确轨迹由教师补充。GRPO 用标签命中更新有组内差异的样本。类别正确是训练奖励，解释是否真的用了正确证据需要单独验证。LEAPS 的教师生成理由时不看人工标签，只保留与该标签一致的生成，在线按原查询与多源候选字段输出二元判定。两篇都用理由辅助训练，人工标签对教师可见范围及上线输出职责不同。

<a id="q-evidence"></a>**扩展后的候选怎样依据多源证据验证原始需求？** LEAPS 用扩展查询召回，验证器读取完整原查询、候选和用户位置等可用情境。商品字段增加离线提取的 OCR、评论、价格、销量和店铺或品牌信息。材质、图案与价格等硬约束需对应明确字段，评论可补充场景证据。论文用二元标签和短理由，没有给证据冲突或字段缺失的确切拒判规则。去掉 CoT 或整组多源信息的消融都降低 F1@20，未逐项隔离字段贡献。训练用验证器奖励，离线最终得分由独立专家判断。[验证器与消融](../../来源/SRC-LEAPS/阅读笔记.md#用商品证据复核完整原句)

<a id="q-budget"></a>**推理训练怎样接到线上预算和排序规则？** TaoSR1 从首个位置的四类 Token logits 得到概率 $p_1$ 至 $p_4$，用同一阈值判断 $p_4+p_3$ 是否够 Good；否则在加上 $p_2$ 后够阈值判 Mid，余下判 Bad。后续按档位排，线上不解码长理由。LEAPS 每商品生成短理由和二元判定，通过分批、滚动与补页控制调用开销。[TaoSR1 的分档算例](../../来源/SRC-TAOSR1/阅读笔记.md#首位置概率足以完成线上分层)与[LEAPS 的验证器](../../来源/SRC-LEAPS/阅读笔记.md#用商品证据复核完整原句)提供两种接口。线上均需将人工相关性、链路时延与实际行为指标分别观察。

## 与精排和评估怎样分工

[精排与概率校准](精排、交互与概率校准.md)保留行为概率、特征交互与效用建模；本模块新增查询满足关系和证据验证这一对象。共享[训练与对齐](训练目标与偏好对齐.md)中的监督分析，但DPO/GRPO学到的奖励、人工相关性和线上行为必须分别定义。查询中的结构信息来自[查询理解](查询理解与结构化表达.md)，验证器接在扩展之后时参看[改写与规划](查询改写与检索规划.md)。

后续比较拟固定相关性标注标准、查询难度和约束类型、候选来源、证据可用时间，分别审查误判、难例召回、验证过滤损失、延迟与线上收益；目前没有跨论文统一实验。阅读入口为[P41 TaoSR1](../阅读/候选论文.md#p41)、[P51 LEAPS](../阅读/候选论文.md#p51)，正式题名、版本与阅读范围见[搜索总图](../总览/搜索系统总图.md#版本与阅读边界)。
