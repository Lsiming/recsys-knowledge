# 因果推断与 Uplift 预估

Uplift 预估关心同类用户接受不同干预时，结果的期望差异。优惠券、营销触达、补贴档位、车型升级都可以是干预；响应概率、转化率或消费额预测则主要描述某个已观测条件下的结果。预测“会买”与预测“因为这项干预而多买”所需的数据和假设不同。

本模块是[营销补贴方向](../总览/营销补贴总图.md)的效应预估入口，也可用于推荐干预等场景。当前已精读 [POUL](../../来源/SRC-POUL/阅读笔记.md) 与 [TaQFormer](../../来源/SRC-TAQFORMER/阅读笔记.md)：前者聚焦组合策略的原子表示与正交化学习，后者聚焦坐标级处理查询、OBS--RCT 适配和在线全动作服务；它们都不是整个因果推断领域的综述。

## 先定义比较，再选择模型

令 $X$ 为干预前用户特征，$Y(t)$ 为干预 $t$ 下的潜在结果。条件平均干预效应为

$$
\tau(x;t,t_0)=\mathbb E[Y(t)-Y(t_0)\mid X=x].
$$

$t_0$ 可以是不发券，也可以是当前策略；换了对照就换了问题。结果可以是固定窗口的订单、GMV、利润或成本，但月度GMV不能直接称终身收益，GMV也不是利润。某个用户只观测一个潜在结果，因此预测通常是特征条件下的平均差异，不是可直接核对的个人真实反事实。

随机实验仍需核对分配单元、分层、触发、对照与窗口；触发后的样本未必仍保持最初随机性。观察数据还需论证一致性、无未观测混杂与重叠。倾向概率与正交化不自动补齐这些识别条件。[POUL §2与§4的具体边界](../../来源/SRC-POUL/阅读笔记.md#预估的是条件平均效应不是可观测的个人真值)可作为检查实例。

## 用什么机制估计哪些增量

| 具体问题 | 可学习的机制与比较条件 | 现有依据 |
|---|---|---|
| 一项干预是单动作，还是整套依场景执行的策略？ | 明确策略规范、动作概率、场景权重；区分完整策略分配与策略内部随机动作 | [组合策略问题](../问题/组合营销策略如何共享结构并估计因果增量.md) |
| 策略频繁重组，怎样借用组件信息？ | 类别ID与联合原子嵌入的区别；置换不变聚合只忽略存储顺序，仍须保留场景—动作关系 | POUL，含纯相加原子编码的退化分析 |
| 如何减少基准预测误差对效应学习的影响？ | 对结果和干预表示残差化；交叉拟合与已知随机化概率；不把局部正交性扩大为任意学习误差保证 | [正交化机制及证明边界](../../来源/SRC-POUL/阅读笔记.md#三项理论分别保证了什么) |
| 联合折扣怎样同时建模和服务？ | 坐标级处理 Token 查询请求记忆，OBS 预训练后用 RCT LoRA 和门适配；通过处理并行复用请求编码 | [TaQFormer 精读](../../来源/SRC-TAQFORMER/阅读笔记.md) |
| 能排序是否就能决定给多少补贴？ | AUUC看排序，分组效应误差看幅度；还要检查支持覆盖、近零分母与区间 | [实验与指标](../../来源/SRC-POUL/阅读笔记.md#实验支持部分排序优势幅度校准仍然不足) |

T-Learner、Causal Forest、DESCN和DRCFR目前只作为POUL论文内部基线理解，不据此声称已独立精读。后续补基础或多值/连续干预资料时，围绕相同目标量、数据生成与支持条件比较，不另建一份同义的“增益模型”百科。

## 与评估、决策和序贯学习怎样衔接

本模块输出的是干预相对于对照的条件效应。预算分配还需把增量价值与成本接入约束，入口见[营销补贴总图](../总览/营销补贴总图.md#从增量预估走向预算决策)。检验预测是否可信及执行后是否产生收益，复用[评估模块](评估、偏差与因果收益.md)；本文主表就展示了排序更好而幅度误差更大的情况。

干预若会改变后续状态、触达疲劳或未来可用预算，需要进入[探索与长期策略学习](探索、长期收益与策略学习.md)，不能把单窗口CATE直接相加当成长期价值。用户特征和随机分配记录由[数据、样本与标签](数据、样本与标签.md)承接；GMV/成本等多个结果的共同学习可联系[多任务模块](多任务学习与多目标决策.md)，但POUL没有给出两项结果共享网络带来独立增益的证据。
