# 数据、样本与标签

推荐模型看到的是日志，不是用户对全部物品的完整偏好。一次点击至少依赖物品是否曝光、所在位置、当时意图和反馈窗口。因此，样本单位、标签定义与可用信息的时间边界应先于模型结构确定。

可以把一条训练记录理解为“用户在时刻 t 的历史与上下文、当时可推荐物品、随后窗口内的行为”。训练特征必须在 t 时可取得；购买等晚到事件还涉及标签何时成熟。未点击曝光与完全未曝光物品具有不同含义，不能因为都记为 0 就认为语义相同。

[RecBole 示例配置](../../来源/SRC-RECBOLE/阅读笔记.md)显式列出分组、排序、切分与评估负样本；[工业论文清单](../../来源/SRC-INDUSTRIAL-REC/阅读笔记.md)另设延迟反馈类别。这些入口支持先把数据协议作为独立问题讨论。DFM的[晚到转化问题](../问题/晚到转化怎样与未转化区分.md)已解释：当前未转化记录同时包含最终负例和延迟正例，不能只根据当前0标签处理；联合似然依赖观察年龄与条件延迟假设，不能替代正确归因。

生成式训练同样需要回答“给定哪段历史，预测哪个后续行为”。将样本写成 Token 序列不会消除曝光选择、晚到标签或时间泄漏。损失如何使用这些样本见 [训练与对齐](训练目标与偏好对齐.md)，协议变化怎样影响数字见 [评估与偏差](评估、偏差与因果收益.md)。

## 生成数据进入推荐训练之前

[DMT综述§3.1](../../来源/SRC-GENREC-DMT/阅读笔记.md#数据侧先区分增强对象再讨论统一)区分内容、表征、行为、结构增强及Agent模拟。它们改变的分别可能是输入、标签、图拓扑和状态转移，不能都叫“新增训练样本”。[生成数据怎样补充真实推荐反馈](../问题/生成数据怎样补充真实推荐反馈.md)集中比较来源标记、可见时间、筛选权重与真实留出验收。

<a id="q-synthetic"></a>没有曝光的伪点击不等于真实正例；由事后评论生成的意图不等于在线时已知查询。冷用户、冷物品、冷场景也要分开定义。[ColdLLM精读](../../来源/SRC-COLDLLM/阅读笔记.md)解释无交互冷物品的过滤—细化与Embedding更新；[Agent4Rec精读](../../来源/SRC-AGENT4REC/阅读笔记.md)解释画像、事实/情绪记忆与分页动作。前者补一次性伪交互，后者生成有状态轨迹；合成反馈的错误传播与真实数据验收在[同一问题页](../问题/生成数据怎样补充真实推荐反馈.md#模拟反馈的标签与验收需要分开)比较。
