# 教程、论文清单与代码资源怎么用

学习推荐系统需要不同用途的资料：教程帮助建立直觉，论文清单帮助发现线索，代码框架帮助理解实现和实验协议。清单分类和仓库可运行性都不能替代原论文证据。

## 按需要选择入口

| 资源与本地解读 | 适合拿来做什么 | 使用边界 |
|---|---|---|
| [Fun-rec](../../来源/SRC-FUNREC/阅读笔记.md) | 中文模块导读，从召回、排序、序列连到生成式路线 | 本轮只读 README 章节入口，未通读课程 |
| [工业搜推广论文清单](../../来源/SRC-INDUSTRIAL-REC/阅读笔记.md) | 找粗排、校准、延迟反馈、多场景和列表优化问题 | 元数据不完全统一，多为维护者 PDF 镜像 |
| [Recommenders](../../来源/SRC-RECOMMENDERS/阅读笔记.md) | 对照算法族、数据准备和不同评估任务 | 示例协议与数字属于具体设置；未运行 Notebook |
| [RecBole](../../来源/SRC-RECBOLE/阅读笔记.md) | 看标准化数据、模型和评估配置接口 | 同一框架仍需控制切分、采样和调参 |
| [FuxiCTR](../../来源/SRC-FUXICTR/阅读笔记.md) | 找特征交叉、兴趣建模、多任务的模型与论文入口 | Model Zoo 收录不代表原作者官方实现或统一最优基准 |
| [生成式推荐清单](../../来源/SRC-GENREC-LIST/阅读笔记.md) | 对照 LLM、语义 ID、架构、训练与扩散路线 | 标签跨多个层次，逐篇还需核对实际任务 |
| [Item ID 专题清单](../../来源/SRC-ITEMID-SURVEY/阅读笔记.md) | 聚焦标识构建、协同对齐、合法生成与加速 | 代码链接混合不同来源，不统一称为官方代码 |
| [Snap GRID](../../来源/SRC-GRID/阅读笔记.md) | 顺着文本向量、语义 ID 和生成推荐理解工程接口 | Snap 框架中的 TIGER 实现不等于 TIGER 原作者代码 |
| [Meta generative-recommenders](../../来源/SRC-HSTU/阅读笔记.md) | 接续序列架构、训练协议和效率实现 | 未运行；README 对比包含不同损失/负样本条件 |

## 从资源入口进入知识

先沿 [总图](推荐系统总图.md)确定要学的模块，再看模块里的问题。需要一个全局生成式视角时，用 [生成式导读](生成式推荐专题.md)跨模块跳转；需要决定下一篇读什么时，用 [候选论文](../阅读/候选论文.md)。框架的比较条件统一回到 [评估模块](../模块/评估、偏差与因果收益.md)，不能把多个仓库的示例数字拼成排名。

检索截至 **2026-10-25**，这九份资料是本次定向取样，不是全领域或最新论文的完整清单。各来源卡固定 commit、原件哈希与实际阅读范围；本轮读取指定 README 范围，并额外读取 Recommenders 的评估目录说明，未遍历论文全文、源码或项目 Issue。后续出现具体理解缺口时再定向补查原始资料。
