# 营销补贴：从因果增量到预算决策

营销补贴决定向谁、在何时、以什么规则给予激励，并判断新增价值是否值得支出。历史消费高或领券后转化高，并不等于这笔补贴产生了同样多的新增消费：一部分用户即使没有补贴也会购买。学习主线因此从干预和对照定义出发，先估计额外价值及成本，再研究预算内如何行动。

若激励通过应用外通知触达，并在月初为用户预选本月发送日，可进一步看[优惠信息Push触达场景](优惠信息Push触达场景.md)：需求预测用于定位候选时段，发送日优劣仍需按相对不触达或现行策略的增量结果验证。

这是与[推荐](推荐系统总图.md)、[搜索](搜索系统总图.md)并列的业务学习方向，按具体职责复用知识模块。新增的主要模块为[因果推断与 Uplift 预估](../模块/因果推断与Uplift预估.md)，当前依据包括组合策略估计论文[POUL](../../来源/SRC-POUL/阅读笔记.md)与联合优惠券处理论文[TaQFormer](../../来源/SRC-TAQFORMER/阅读笔记.md)。TaQFormer 还给出了受成本率约束的单次请求选券规则。多期投放中，今天发券怎样改变明天的用户状态，是另一项待研究的问题。

当手头是旧策略积累的非随机发券日志，先检查高意向用户是否更容易拿券。DeR-CFR 尝试平衡同时影响指派与购买的因素，估计固定券相对于不发券的条件转化差。核销成本和预算再进入决策层。[历史发券与增量估计](../问题/历史发券日志如何估计补贴增量.md) · [DeR-CFR 精读](../../来源/SRC-DER-CFR/阅读笔记.md) · [MIM-DRCFR 精读](../../来源/SRC-MIM-DRCFR/阅读笔记.md)

当券改变了用户的店铺选择，需以同一窗口全平台的结果计算增量。CanniUplift 用平台总 GMV 对齐候选预测，并用核销标签拆分处理组的两条结果路径。 [跨店替代与平台净增量](../问题/跨店替代时怎样估计补贴的平台净增量.md) · [CanniUplift 精读](../../来源/SRC-CANNIUPLIFT/阅读笔记.md)

商品价格可以从[历史条件化的单调需求曲线](../问题/商品历史如何生成单调需求曲线并支持定价.md)进入：TG-DIPricingNets先预测各倍率销量，再枚举商品毛利最大价格。它与补贴共享“响应预测—成本口径—动作选择”的分工，但本篇是观测销售预测和历史回测，不能把单调结构或5.94%的分组利润差当作已识别的补贴因果收益。

## 让干预、效果与成本形成一条链路

```mermaid
flowchart LR
    D[干预前特征、随机分配与触发记录] --> C[因果推断与 Uplift 预估]
    T[干预规范与对照策略] --> C
    C --> V[增量价值与增量成本]
    V --> B[预算和可执行约束下选择策略]
    B --> E[随机实验验证净增量]
    E --> D
```

这是一种决策问题分解，不代表POUL已经实现整条链路。尤其要保留“未触发”“未领取”和“实际核销”等不同事件：它们可能处于随机分配之后，直接按这些事件筛选用户会改变估计对象。规则定义应从[数据与标签](../模块/数据、样本与标签.md)回查。

## 从增量预估走向预算决策

设 $t_0$ 为对照，$\tau_V(x;t,t_0)$ 为价值增量，$\tau_C(x;t,t_0)$ 为成本增量。一个帮助区分估计与决策的形式化接口是

$$
\max_{\pi}\ \mathbb E[\tau_V(X;\pi(X),t_0)]
\quad\text{s.t.}\quad
\mathbb E[\tau_C(X;\pi(X),t_0)]\le B.
$$

$\pi(X)$ 是为用户选择的策略，$B$ 在这里是相对对照的平均增量成本预算。这是问题分解用的数学定义，并非POUL提出或求解的优化算法。若业务给的是绝对支出预算，就需用策略下的总成本；若价值是GMV，还需按利润口径转换。券面额、核销支出和增量成本不能互换。

POUL分别报告GMV与Cost效应，提供了上游估计接口，但主表8项MAPE均未优于全部基线，说明只看排序就做金额决策仍有风险。价值、成本的尺度、误差与不确定性都应进入策略验证；在具体任务明确之前，不设固定ROI阈值或擅自选择业务指标。

TaQFormer 约束整批请求的预期补贴支出与预期业务价值之比。固定拉格朗日乘子后，每次请求可以分别为可行券档打分，乘子在历史流量上校准到目标成本率。深券与浅券的预测成交率即使保持相同的差值，两者的预测绝对水平仍会影响选券。见[两种券的算例与线上对照](../问题/组合营销策略如何共享结构并估计因果增量.md#同样的增量为什么会选出不同的券)。[TaQFormer v1 §3.3，式 (5)–(6)，PDF 第 3 页](https://arxiv.org/pdf/2610.26199v1#page=3)

## 从这篇论文继续学什么

先读[POUL精读](../../来源/SRC-POUL/阅读笔记.md)，理解两层随机概率、策略混合表示、残差化和证据限制；再读[TaQFormer精读](../../来源/SRC-TAQFORMER/阅读笔记.md)，理解坐标级处理查询、OBS--RCT适配和处理并行服务；沿[组合策略问题](../问题/组合营销策略如何共享结构并估计因果增量.md)比较类别ID、分别回归、组件共享与联合处理查询。

后续可沿二元 CATE、连续激励、跨期预算和长期投放继续阅读。实验触发已有 Tang 等的对照日志方法，例如优惠券改变领取率时，仅比较两组实际领取者会改变样本人群。若要分析共同的可触达人群，需要在对照组也能判定同一触发条件。见[分配与触发](../问题/线上实验怎样复用流量并识别真实增量.md)及[Tang 等 §5.2.2，出版页 23](https://doi.org/10.1145/1835804.1835810)。

价格分支可读[TG-DIPricingNets精读](../../来源/SRC-TG-DIPN/阅读笔记.md)，沿“历史 → 参数 → 单调需求 → 利润枚举”走完教学商品，再与TaQFormer的联合响应和POUL的对照效应比较。该文的DWMAPE是分组预测误差，利润表是历史分组比较；两者都不能替代随机策略净收益验证。
