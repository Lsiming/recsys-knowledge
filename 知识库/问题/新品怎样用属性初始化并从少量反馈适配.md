# 新品怎样用属性初始化并从少量反馈适配

广告刚上线时，原预测塔仍能看到用户、上下文与广告属性，但 ID 表没有该条目。之后收到第一批点击时，可以单独更新这个 ID。冷态需要从已知属性构成初值，热身需要明确第一批标签更新谁、更新后在哪些样本上测。

## 零反馈时先确认向量进入哪一步

[EGES](../../来源/SRC-EGES/阅读笔记.md) 给无行为新品取已学习属性向量的均值，将其用于图表征兼容的物品检索。广告精排里的 [Meta-Embedding](../../来源/SRC-META-EMBEDDING/阅读笔记.md) 把属性交给可微生成器 $g_w$，输出与 ID 查表相同维度的初始向量。前者读出检索向量，后者接进冻结基座预测 CTR 或 CVR。新品是否有候选曝光、标签是否成熟，还取决于召回、探索和日志时间窗。

## 用后来的反馈判断初值是否便于更新

[MAML](../../来源/SRC-MAML/阅读笔记.md) 为每个历史任务构造支持集 $S$ 与查询集 $Q$。先做 $\theta'=\theta-\eta\nabla L_S(\theta)$，再将 $L_Q(\theta')$ 反传给共享初值。外层梯度经过内层更新算子，乘 $I-\eta H_S$ 的转置，一阶近似略去内层损失的曲率。查询表现检验学习到的起点能否被少量数据修正。[MAML §2，算法 1](https://arxiv.org/pdf/1703.03400v3#page=2)。

新品场景中可把任务限定为一个旧广告 ID，把待更新参数限定为它的表示。设 $e_0=g_w(a)$，从该广告一批反馈 A 做 $e_1=e_0-\eta\nabla_e L_A(e_0)$，再用另一批反馈 B 计算 $L_B(e_1)$。Meta-Embedding 用 $\alpha L_A(e_0)+(1-\alpha)L_B(e_1)$ 训练生成器，兼顾初次曝光与热身质量。实际新广告首次用属性生成，反馈后只更新对应 ID 向量。[Meta-Embedding §3，式 (12)–(17)](https://arxiv.org/pdf/1904.11547v1#page=4)。

## 分别测初态、少量适配和稳态

评估按新 ID 隔离，并把反馈按实际可见时间切开。记录零标签初态的打分、同样 $K$ 个成熟标签更新后的打分、进入候选的比例及稳态效果。Meta-Embedding 表 2 在离线构造的新旧 ID、热身批和留出集上比较初始化，使用六种基座与三种任务数据，百分比相对冷态随机基线。MAML 的图像与回归结果验证少样本优化过程，实际线上曝光和反馈选择需要另外核对。[Meta-Embedding 表 1–2](https://arxiv.org/pdf/1904.11547v1#page=7) · [MAML §5](https://arxiv.org/pdf/1703.03400v3#page=5)。

[多场景共享](多场景怎样共享模型又保留差异.md) 在已知域的预测上调制参数或表示。新品适配按一个新 ID 自己的反馈更新表示，两者可在同一个服务中各自评估。
