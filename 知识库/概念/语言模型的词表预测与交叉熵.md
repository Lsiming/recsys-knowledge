# 语言模型怎样从Token预测走到交叉熵与梯度

自回归语言模型把一段文本拆成许多“已知前缀，预测下一个Token”的监督对。Transformer为每个输入位置生成隐藏状态，语言模型头把状态投影到词表，交叉熵衡量目标Token得分是否足够高。同一个损失再沿计算图更新输出投影、注意力、前馈和输入嵌入。

## 一个序列怎样提供多个预测目标

用教学序列`[起始符, 我, 爱, 猫, 结束符]`说明；这些中文词只是示意Token，不代表GPT的真实BPE切分。输入与标签可由同一数组切片：

| 输入位置 | 输入Token | 该位置可读的输入 | 预测标签 |
|---|---|---|---|
| 0 | 起始符 | 起始符 | 我 |
| 1 | 我 | 起始符、我 | 爱 |
| 2 | 爱 | 起始符、我、爱 | 猫 |
| 3 | 猫 | 起始符、我、爱、猫 | 结束符 |

若完整数组为$x_{0:T}$，模型输入$x_{0:T-1}$，标签$x_{1:T}$。因果mask允许读输入的当前位置及左侧；这不包含该行待预测的下一个Token。GPT论文式(1)按“被预测Token”索引，因而写只看它之前的上下文；两种写法是同一错位关系。

Transformer输出$H\in\mathbb R^{B\times T\times d}$，每个输入位置都有一个状态。每行监督自己的下一个Token，所有有效行参与语言模型损失，而非只取最后一行。最后位置单独读出是另一种[序列分类方式](Token表示怎样汇聚成序列表示.md#专用提取位置与最后真实token)。[GPT §3.1式(1)–(2)，PDF第3页](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf#page=3)；官方微调代码用`h[:, :-1]`对`X[:, 1:, 0]`，见[固定代码解读](../../来源/SRC-GPT1-CODE/阅读笔记.md#错位标签与损失平均)。

## 隐藏状态怎样映射到词表

设词表大小$V$，独立输出权重$W\in\mathbb R^{d\times V}$、偏置$b\in\mathbb R^V$。对隐藏行向量$h_t$，

$$z_t=h_tW+b,\qquad p_{tv}=\frac{e^{z_{tv}}}{\sum_{j=1}^V e^{z_{tj}}}.$$

批量logits $Z$的形状为$[B,T,V]$。Logit是未归一化实数分数，概率是沿词表轴归一化后的分布；整数标签$y_t$选出正确词表项，one-hot向量$q_t$只是同一标签的另一种表示，不是模型输出。这里的Softmax沿词表，Attention中的Softmax沿Key位置，不能混为一处。

若与输入表$E\in\mathbb R^{V\times d}$共享，令$W=E^\top$；GPT论文式(2)写$HE^\top$，没有另写输出bias。共享指同一参数被两条路径使用，不能只复制一次初值。详见[输入查表与输出打分](词表嵌入与权重共享.md#查一行向量与给整个词表打分)。官方ROCStories代码的合并表投影比这条Token表基式更具体，见[代码中的we](../../来源/SRC-GPT1-CODE/阅读笔记.md#共享表为何还包含位置行)。

## 交叉熵为什么直接接收logits

对单个无类别加权、无标签平滑的整数标签$y$，

$$\ell=-\log p_y=-z_y+\log\sum_j e^{z_j}.$$

取$m=\max_j z_j$，数值稳定地计算

$$\ell=-z_y+m+\log\sum_j e^{z_j-m}.$$

例如$z=[1000,1001]$，直接指数可能溢出，减去1001后只需计算$e^{-1}$和1。先显式Softmax再取log还可能把小概率舍入为0；稳定LogSoftmax直接计算对数概率。

PyTorch的`CrossEntropyLoss`接收logits；对类别索引标签，数学上等价于LogSoftmax加NLLLoss。不能先Softmax再传同一接口，否则它会把概率当作新的logits。接口还支持概率标签、类别权重和标签平滑，需按实际参数解释归约；这不是GPT原实现采用PyTorch的意思。[固定PyTorch接口说明](../../来源/SRC-PYTORCH-CROSSENTROPY/阅读笔记.md#logits输入与标签形状)。

```python
# PyTorch教学写法，logits:[B,T,V]，labels:[B,T]，标签已错位
loss = torch.nn.functional.cross_entropy(
    logits.reshape(-1, V), labels.reshape(-1), ignore_index=-100
)
```

原样传$[B,T,V]$会把第二维当类别轴；也可先换成$[B,V,T]$。`ignore_index=-100`要求被忽略标签实际改为-100，并不自动识别任意PAD ID；整批没有有效标签时须单独处理。

## 为什么logit梯度是概率减去标签

令$p_i=e^{z_i}/\sum_k e^{z_k}$，商法则得到

$$\frac{\partial p_i}{\partial z_j}=p_i(\mathbf1_{i=j}-p_j),\qquad J_{\operatorname{softmax}}=\operatorname{diag}(p)-pp^\top.$$

对目标分布$q$，设$\sum_iq_i=1$且$q$不依赖$z$，

$$\ell=-\sum_iq_i\log p_i,\qquad\frac{\partial\ell}{\partial p_i}=-\frac{q_i}{p_i}.$$

沿所有概率分支求和：

$$\frac{\partial\ell}{\partial z_j}=\sum_i\left(-\frac{q_i}{p_i}\right)p_i(\mathbf1_{i=j}-p_j)=-q_j+p_j\sum_iq_i=p_j-q_j.$$

也可直接对$-z_y+\log\sum_j e^{z_j}$求导，得到$p_j-\mathbf1[j=y]$。因此$\partial\ell/\partial z=p-q$，one-hot标签时常简写$p-y$，其中$y$必须理解为one-hot向量，不能拿概率向量直接减一个类别编号。

例如$p=[0.2,0.5,0.3]$、正确类别为第三类，则梯度为$[0.2,0.5,-0.7]$；负梯度方向提高正确类logit、降低其他类logit。更新后实际变化还受学习率、共享参数、优化器和其他样本影响。

这也解释了错误且过度自信的分类仍可能有较大logit梯度；不能只看到Softmax Jacobian趋小，就断言交叉熵梯度必消失。Attention权重后的上游目标不同，不可直接把$p-q$套到Attention logits。上面是对概率与损失定义的数学推导，非论文新增实验。

## 多位置损失怎样归约

令$m_{bt}$表示该目标是否有效，按有效Token平均的一种目标是

$$\mathcal L=\frac{1}{N}\sum_{bt}m_{bt}\ell_{bt},\quad N=\sum_{bt}m_{bt},\quad \frac{\partial\mathcal L}{\partial z_{btv}}=\frac{m_{bt}}{N}(p_{btv}-q_{btv}).$$

若按序列先平均再按batch平均，长短序列的相对权重不同。官方微调脚本先按每条候选序列有效目标数归一化，再取平均；论文式(1)写求和。辅助LM系数$\lambda$的实际尺度因此还依赖归约约定。[官方错位和平均方式](../../来源/SRC-GPT1-CODE/阅读笔记.md#错位标签与损失平均)。有类别权重、不同样本权重、温度或标签平滑时，应把相应因子或目标分布一并代入，不能只写裸$p-q$。

## 梯度怎样穿过LM头和共享Embedding

把有效位置展平成$H\in\mathbb R^{N_{pos}\times d}$，令$Z=HW+b$，上游$G=\partial\mathcal L/\partial Z$已包含mask和归约因子，则

$$\frac{\partial\mathcal L}{\partial H}=GW^\top,\qquad\frac{\partial\mathcal L}{\partial W}=H^\top G,\qquad\frac{\partial\mathcal L}{\partial b}=\sum_tG_t.$$

共享时$W=E^\top$，输出路径对$E$的贡献是$G^\top H$；总梯度还要加上经隐藏状态、输入查表回来的贡献。输入路径按使用到的Token行累加，完整Softmax输出路径通常涉及全词表行。[共享参数梯度](词表嵌入与权重共享.md#查一行向量与给整个词表打分)。

$\partial\mathcal L/\partial H$继续穿过最后Block、逐层LN/残差、Attention和FFN，最终回到输入Embedding。参数共享意味着各次使用的梯度相加，冻结或detach则会改变路径；优化器随后才用这些梯度更新参数。[LN与残差链式法则](LayerNorm与残差梯度.md#pre-ln的恒等梯度项从哪里来)。

## Attention中的Q、K、V怎样接到反传

对单头忽略Dropout，令$S=QK^\top/\sqrt{d_k}+M$、$A=\operatorname{softmax}_{row}(S)$、$O=AV$。给定上游$D=\partial\mathcal L/\partial O$，

$$D_V=A^\top D,\qquad D_A=DV^\top,$$

$$D_{S,ij}=A_{ij}\left(D_{A,ij}-\sum_kA_{ik}D_{A,ik}\right),$$

$$D_Q=D_SK/\sqrt{d_k},\qquad D_K=D_S^\top Q/\sqrt{d_k}.$$

在合法的理想遮罩行，禁止边$A_{ij}=0$，对应分数梯度也为0。令$Q=XW_Q,K=XW_K,V=XW_V$，则每组投影有$D_{W_Q}=X^\top D_Q$等，输入收到三路和$D_X=D_QW_Q^\top+D_KW_K^\top+D_VW_V^\top$，再加残差等其他路径。多头还需穿过输出投影与拼接，训练Dropout则另乘本次mask的缩放；这些公式解释裸单头核心。

这里直接对[点积注意力定义](../问题/序列怎样用自注意力建立上下文.md#从相似度到可学习的信息读取)作链式法则展开；交叉注意力的Q输入与K/V输入不同，梯度相应回到两侧。
