# 逐位置前馈层的门控与宽度

注意力从其他位置读取信息。逐位置前馈层接收每个位置已经汇聚的上下文向量，在该位置内混合特征。对整个序列，同一组前馈参数作用在所有位置。普通 FFN 对输入做一次升维、激活、一次降维。门控 FFN 在降维前让两个可学习特征相乘，改变的是每个隐藏通道产生值的方式。[原始 Transformer §3.3](https://arxiv.org/pdf/1706.03762v7#page=5) · [GLU 变体 §1–2](https://arxiv.org/pdf/2002.05202v1#page=1)

## 两路投影怎样分工

令 $x$ 为一个位置的行向量，宽度为 $d$。忽略偏置，普通 FFN 计算 $\phi(xW_1)W_2$。门控版本计算 $(\phi(xW)\odot(xV))W_2$，其中 $W,V\in\mathbb R^{d\times m}$，$W_2\in\mathbb R^{m\times d}$，$\odot$ 表示逐元素乘法。$W$ 和 $V$ 从同一输入学习不同投影。若一个通道的两路都是线性函数，相乘就能表达二次交互。加入非线性后，激活一路可以有选择地放大、减弱或变号。

| 变体 | 激活支路的 $\phi(z)$ | 单通道行为 |
| --- | --- | --- |
| Bilinear | $z$ | 两个同输入线性投影逐通道相乘 |
| GLU | $\sigma(z)$ | 用 0 到 1 之间的系数控制值支路 |
| ReGLU | $\max(0,z)$ | 非正预激活使该通道输出归零 |
| GEGLU | $z\Phi(z)$，$\Phi$ 为标准正态分布的累积分布函数 | 近零处平滑调制，负值可留下带符号的输出 |
| SwiGLU | $z\sigma(z)$，论文 FFN 实验取 $\beta=1$ | 用 sigmoid 平滑调制自身，再乘值支路 |

这五个门控变体的输出宽度均回到 $d$。它们可以保留注意力、残差与任务监督接口。对第 $i$ 个隐藏量 $u_i=\phi(a_i)v_i$，给定 $\partial L/\partial u_i=g_i$，两路梯度分别为 $g_iv_i\phi'(a_i)$ 和 $g_i\phi(a_i)$。由此可见当前样本的一路状态会影响另一路收到的梯度。该公式描述局部反传，训练稳定性和泛化仍取决于完整模型及训练条件。[SwiGLU 公式与 T5 样本示例](../../来源/SRC-SWIGLU/阅读笔记.md#从一次激活到同一通道两路相乘)

## 相同参数预算怎样选宽度

普通 FFN 两个矩阵有 $2dm_0$ 个参数，门控 FFN 三个矩阵有 $3dm$ 个参数。取 $m=\tfrac{2}{3}m_0$，恰好匹配无偏置权重数和主要矩阵乘加的数量。实际宽度可能为硬件和并行切分对齐而取整。激活、逐元素乘法、张量驻留和算子融合会改变实际耗时及峰值内存，应另外测量。

Shazeer 的 T5 Base 把隐藏宽度从 3072 缩到 2048，同训 524,288 步时，门控 GEGLU 和 SwiGLU 的 C4 留出集对数困惑度分别为 1.633 和 1.636，普通 ReLU FFN 为 1.677。同表中普通 FFN 只把 ReLU 换成 Swish 时为 1.683。与 SwiGLU 的 1.636 对读，差别还涉及值支路、逐通道乘法和匹配预算后的隐藏宽度，无法将收益单独归因于 Swish。各下游开发集的最优变体不同。用这组结果比较相同矩阵预算下的模型质量时，需要保留 C4 片段恢复、T5 Base、同训练步数和混合微调的条件。[固定版表 1，第 2 页](https://arxiv.org/pdf/2002.05202v1#page=2) · [论文结果及对照边界](../../来源/SRC-SWIGLU/阅读笔记.md#实验比较了哪些质量变化)
